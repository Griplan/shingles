# 当前人体资源：Commons CC0 中性线稿

当前入口为 [commons-v1.ts](commons-v1.ts)：`commons-neutral-v1 / 4.0.0`，geometryId=`commons-blank-cc0-v1`，regionSetId=`commons-blank-cc0-v1-ui-regions-1`。实际 Canvas 加载本地 [正面 PNG](commons-cc0/front.png) / [背面 PNG](commons-cc0/back.png)，不是旧路径换名。来源、作者、CC0条款与修改说明见 [NOTICE](commons-cc0/NOTICE.md)；原始SVG及派生SVG、哈希、生成轮廓均本地保留。

原素材的颈肩、膝踝和掌指形状由真实源图提供，停止手工改造旧人体。相同等比尺度将两面放在400×900画布，背景留白保留。身体内部统一浅色衬底，源线条保留；没有独立拉长腿、扩大肩或缩头。

[当前区域](../../data/body-regions.ts)为本素材重新配准的16个粗UI区域，bounds同时作为局部放大范围；旧v3区域原样保存在[历史区域表](../../data/body-regions-v3.ts)。命中/裁剪轮廓来自同一源图栅格，前后独立，不能强制共用。归一化公式不变，旧点不自动迁移。BODY_LANDMARKS仅为逐视图人工工程参考；背面occiput表示后枕，不能当作正面的下颌位置。

构建（离线，不安装运行依赖）：`backend/.venv/bin/python scripts/prepare_commons_body.py --sharp <现有Sharp模块绝对路径>`，在项目根目录执行。只接受经核验的固定SHA原文件；脚本生成当前素材目录下的派生文件、轮廓与manifest，临时缓冲放在专用临时目录并清理。依赖项目已装Shapely及工具环境Sharp，未增加小程序依赖。需要修改源文件时必须重新审查来源并升级模板，而不是绕过SHA检查。

组件通过Canvas节点createImage异步加载，再drawImage；加载中不发布有效视口，失败明确提示并可重试，不退回旧人体。每面图片有节点内缓存，换面、hide/detach及过期回调受隔离。SVG只作为编辑源，不要求微信运行时支持SVG解码。
