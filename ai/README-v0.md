# 可选 AI 模块

当前 **V0 仅创建目录和文档**，没有模型、下载、训练、推理或第三方 AI 调用。AI 为可选 V7 研究，实际进度与实验结果只记入 [task.md](../task.md)。

## 1. 目录

| 目录 | 未来用途 |
| --- | --- |
| experiments/ | 实验配置、可复现脚本及脱敏材料 |
| inference/ | 可独立关闭的推理适配 |
| models/ | 本地模型权重，权重由 .gitignore 排除 |

V0 仅 .gitkeep，不创建假权重、假 Mask 或推理结果，不将模型依赖加入核心后端启动路径。

## 2. 未来职责与算法候选

研究合法照片上的人工提示分割、可编辑病灶 Mask/轮廓，以及相较纯手工的修正成本。候选包括 SAM 类交互分割、提示点/框引导、预训练病灶分割与传统图像处理基线。仅为方向，尚未选型、安装或验证。

模型选择依据数据、许可、资源和实际收益，不预设 AI 必然更准或更省时。

## 3. 不承担什么

不作确诊、治疗建议或真实受累神经节判断，不编造皮节图谱，不取代人工审核。照片 Mask 属于图像坐标，不能直接等同标准人体图谱位置。

照片到标准图谱的姿态、视角、尺度和解剖配准是独立问题；无验证过的配准与人工确认，不送入皮节匹配。分割分数不是诊断置信度。

## 4. 输入输出草案（未实现）

输入只包含获准处理的去标识化图像、可选人工提示和必要参数，不要求身份。图像坐标与图谱坐标使用明确不同的类型/元数据。

输出可为图像坐标 Mask/轮廓、图像尺寸/方向、模型/配置版本、人工修正提示及处理记录。具体 Schema 待获准开发时确定，当前无可调用 AI API 或预填质量分数。

进入核心前需：人工检查分割 → 独立验证的配准或手工转录 → 确认图谱版本/视图 → 转为与人工标注一致的归一化多边形。后端对其执行相同输入与图谱准入检查。

## 5. 解耦

后端 app 不导入 ai；人工流程、规则服务和 health 不以权重、GPU 或外部 AI 为启动前提。AI 不加载或修改正式图谱，只提供待确认建议。未来独立管理 AI 依赖与权重，关闭或失败时仍可手工标注。先确定最小契约，不提前引入微服务或队列。

## 6. 数据与隐私

必须有合法来源、使用目的、许可、去标识化、受控存储和删除策略。照片、Mask 与可关联个人的资料不入公开仓库或未经批准的第三方。模型权重放 models 并忽略；权重开源不代表患者数据可上传。

定量实验需要参考标注及明确划分，记录标注协议、人员与争议处理，按个体隔离训练/调参/测试以避免泄漏。没有参考标注只能做限定探索，不报告虚构 Dice、IoU 或医学准确率。完整约束见 [privacy.md](../docs/privacy.md)。

## 7. 实验记录

每次在 task.md 追加标识、日期、问题、数据来源、模型/权重及许可、代码/配置、随机种子、预处理、硬件环境、命令、结果、证据、失败与限制。experiments 可保存真实配置和脱敏结果，由 task.md 引用；不得覆盖失败或预生成成功报告。

候选指标为 Dice、IoU、实测推理耗时、人工修正时间/次数。明确参考 Mask、空 Mask 处理及统计单位；耗时记录设备/尺寸，人工成本使用统一任务。纯手工、原始模型和修正后结果分开，不以修正后结果冒充自动预测。这些指标不证明解剖定位或诊断能力。当前全部 AI 实验为 NOT_RUN。

## 8. 引入真实模型的条件

用户明确授权 V7；核心人工与规则闭环稳定；合法数据和参考标注就绪；许可、隐私、计算与人工预算满足后，才开始小规模可复现实验。是否接入依据收益和失败案例；V7 可跳过，核心交付不依赖 AI 成功。
