**服务端无法验证微信手机“开发调试”状态。免邀请意味着其他互联网客户端也可以申请有限测试会话。该会话是照片隔离凭据，不是用户资格或微信身份验证。** 本轮明确不以 envVersion/debug 字段伪装鉴权，不添加公开的固定共享密钥，也不假称只能微信访问。

仅 controlled 环境且 `ENABLE_PUBLIC_TEST_ACCESS=1` 开放自动建会话，默认关闭；production即使误设该开关也不开放。仅对本B服务启用，A不变。

其他业务接口仍需自动Bearer；照片还需独立照片key和同一principal，另一个自动会话即使持有照片key也不能读取、修改或删除。限制10MiB照片/3MP解码像素、30分钟照片TTL、取消/过期清理、真实Mask及几何契约均不变。旧邀请交换保留作为回退兼容，普通小程序已没有邀请输入路径，原生成邀请脚本不再需要。

**HTTP的照片和临时令牌不加密，只允许公开授权或合成图片，禁止患者照片；不要作为正式医疗或患者上线方案。** 客户端传输提醒继续保留。免邀请降低了访问资格限制，现有限流只能约束资源，不能阻止所有滥用。测试完仍应关闭公网测试入口。
