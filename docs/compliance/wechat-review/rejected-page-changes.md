# 指定图片页面文案变更

变更仅发生在 `miniprogram/packages/clinical/pages/ai-annotate/` 的 JSON、WXML 和 TS。该页面使用原生导航标题，顶部正文只保留正面／背面，用于确认当前放置方向。初始部位提示数据继续由原流程传递。

| 原文案 | 现文案 |
|---|---|
| AI 辅助标注 | 图片辅助标注 |
| 上传一张局部皮肤照片 | 上传一张局部照片 |
| 圈住皮疹，AI辅助识别范围 | 圈选目标区域，自动提取轮廓 |
| 从相册上传 | 从相册选择 |
| AI辅助结果需自行确认，不用于诊断 | 提取的轮廓需自行确认，仅供位置标注参考，不作为医疗诊断依据。 |
| 正面／背面 · 自由放置（或附初始部位提示） | 正面／背面 |
| 正在 AI 分析… | 正在处理图片… |
| 正在切换结果… | 正在切换候选轮廓… |
| AI 分析完成，请检查绿色范围，再确认。 | 轮廓提取完成（自动化图像分割），请检查绿色范围，再确认。 |
| 这次没有得到合适的识别范围，请重新圈选。 | 轮廓提取失败，请重新圈选。 |
| 请框住需要识别的皮疹区域；再框住一处需要识别的皮疹区域 | 请框住所需的目标区域；再框住一处需要提取轮廓的区域 |
| 确认识别范围；恢复原识别；重新识别；换个结果 | 确认轮廓；恢复原轮廓；重新提取；换个候选轮廓 |
| 局部／整图分析；识别不准确？可微调范围 | 局部／整图提取；轮廓不合适？可微调范围 |
| 正在准备人体轮廓 | 正在准备轮廓放置 |
| 服务器临时用于 AI 辅助圈定范围；闲置 15 分钟；进入放置即释放 | 服务器临时用于自动化图像分割提取轮廓；放置页就绪、取消或返回时请求删除，闲置会话由服务端自动回收 |

保留拍照、返回手动标注、照片用途与隐私、取消并删除照片、上传前同意、公开或合成测试图片限制、HTTP 调试时的明文风险告知及非诊断边界。由共享状态和服务返回的警告、异常只在本页显示时转换已知措辞，没有更改接口状态码、共享错误或失败分支。WXML 的重复提示过滤与页面错误文案同步修改。布局样式、上传、分割、候选修正、确认、人体放置及照片会话删除机制保持原实现。
