# 实际业务功能与可见范围

审查基于 2026-11-24 当前源码、已注册路由、模板与条件渲染、接口实现、部分生成数据的展示元数据、已知部署记录及图像资源。平台端状态需要另核实。

| 检查项 | 核对结果与代码依据 |
|---|---|
| 注册页面 | `miniprogram/app.json` 共 9 个。主包先进入完整人体、另有项目首页。临床分包有标注及同页参考结果、旧结果跳转页、开发图谱、图片辅助标注、放置。特殊分包有目录和统一局部页，参数区分左右脚底、左右腋下及会阴 |
| 手工标注、结果与放置 | 人体正背面可手动圈选。图片轮廓由用户调整移动、缩放、旋转、方向，再确认位置。支持越界检查；结果页用标签及高亮查看参考区域。旧 result 页只引导返回工作区 |
| 图片不是问答 | `backend/app/api/routes/ai.py` 的会话、照片上传、分割、编辑、确认、资源和删除接口与小程序照片页吻合。MobileSAM 接收照片和框／点，输出 Mask、分数及候选轮廓。画笔修改已有 Mask，也无疾病分类。未见聊天、问答、用户自由输入与文本回复接口、文本大模型调用、AI 绘画或医疗报告生成 |
| 参考匹配 | `backend/app/api/routes/evaluate.py` 接收用户确认的标注与图谱身份。Shapely 求交计算参考区域覆盖。局部模拟图谱如实区分。未发现把匹配作为诊断、治疗建议、用药或受累神经判断的执行分支 |
| 医疗服务 | 检查页面、跳转、组件事件、上传及 API 路由和依赖，未见在线医生、预约挂号、问诊、联系特定医生、处方或保健指导模块。开发面部图谱有一条静态就医提醒（R17） |
| 环境、调试和分享 | `miniprogram/config/environment.ts` 中 develop 和 trial 可启用匹配、照片与放置，release / unknown 关闭相应在线能力，调试仅开发能力开放。仓库未见自定义分享回调标题或描述、客服 contact、外部小程序跳转及 web-view。微信默认分享及账号展示另核实 |
| 设置、关于、协议和隐私 | 无独立设置、关于、使用说明、隐私政策、用户协议注册页。标注说明抽屉有来源、许可及减少动态效果选项。照片页有用途与隐私弹窗及上传前确认，首页有隐私摘要。仓库内使用说明和隐私文档不等同于账号公示 |
| 文案来源与异常 | 审查 WXML、JSON 标题、动态 `setNavigationBarTitle`、Toast、Modal、Loading、无障碍标签、状态拼接和前后端错误映射。CSS 用于样式，指定页未发现伪元素文案。开发工具配置的项目描述不等同于正式名称或简介 |
| 图像文字 | 查看 7 张运行 PNG，人体正背面、左右腋下及足底图上未见功能宣传文字。会阴图有示意方向及解剖参照文字，应保留并与模拟声明一起理解。原人体 source.svg 有源素材文字节点，运行采用正背面 PNG。局部 SVG 的 title 属资源说明，配置排除 SVG 上传，未发现直接参与小程序页面显示的嵌字医疗服务承诺 |
