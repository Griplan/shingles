# 医疗相关文案审查

- **首页与导航**。「人体病灶辅助定位」出现在首页及全局默认标题。「带状疱疹神经皮节辅助定位系统」在 FastAPI 元数据，属于开发接口资料，未绑定到小程序页面。建议按实际区域标注与参考匹配统一，见 R01、R18。
- **手动标注、放置及特殊部位**。「病灶」多用于现有轮廓标签或错误提示。没有发现这些分支在作出疾病判断。可改为「标注轮廓」「局部区域标注」，保留人体内外判定和用户确认含义，见 R06、R09–R16、R20。
- **结果数值**。候选百分比表示对应参考区域和标注的面积交集占比，总覆盖采用并集，候选可能重叠。未发现生产结果将此数值标为患病概率、识别准确率或确定受累神经。保留参考和非诊断限制。零结果可按 R07、R16 更直接说明当前图谱未匹配。
- **图谱和资源**。足底为来源参考图谱，腋下和会阴为人工模拟，医学审核待完成。保留模拟字样、图谱来源、署名与许可。人体及局部示意本身不构成临床图谱，见 K01、K03。
- **开发图谱预览**。面部分组有眼周或鼻部皮疹、视力变化时及时就医的一条静态提示。当前源码仅受控开发可进入。提示不构成个体化诊疗，但应作为真实存在的健康提醒单独列明，见 R17、P02。
- **账号侧资料**。应用名称、简介、服务类目、隐私指引、用户协议、送审截图与实际审核版本由账号管理方提供后核对，见 P02–P04。
