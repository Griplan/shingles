## 保留词语及原因

- **自动化图像分割、MobileSAM、Shapely、AI 技术名**。准确交代自动化处理、工具和算法。图片结果与弹窗仍披露自动化处理，代码符号及 API 契约保留。
- **患者照片、上传、HTTP 明文、训练、删除**。必须说明测试对象限制、处理目的和去向、空闲期限与请求删除。运行代码没有照片训练链。
- **诊断、医学审核、静态就医提醒**。用于界定用途及说明安全事项。开发图谱预览中只有相关面部分组展示提醒。
- **神经名称、参考与模拟、图谱出处及许可**。保留实际图谱标签、解剖左右、高亮、几何覆盖、用户修改以及人工模拟与来源区分。
- 复核了 WXML、JSON 标题、WXSS `content`、动态 TS、Toast／Modal／Loading、服务错误、用户材料和无障碍标签。图像沿用既有 7 张运行 PNG 及对应资源，静态示意的方向／解剖参考字样保留。历史技术及测试材料中的原文按其时间语境保留。
