# AI 相关文案审查

- **直接可见**。指定页已明确输出为候选轮廓，并在结果状态和照片用途弹窗中说明自动化图像分割。全身入口卡片及运行失败仍可能显示泛称「AI 辅助标注／辅助识别」，见 R02、R03。
- **条件可见**。全身标注结果和编辑按钮、放置页门禁报错、特殊部位未开放照片能力提示，见 R07、R08、R09、R13、R15。尤其「自动放置未开放」有歧义，真实业务一直要求用户确认人体位置。
- **动态及接口**。共享照片状态提供候选轮廓警告、重新识别及修正提示，传输服务按错误码映射，后端也有原始错误文本。阶段一仅在本页显示入口转换这些文字，其他落点按 R19 待审。
- **保留披露**。自动化处理、服务端接收、候选轮廓须人工检查、使用限制和隐私说明应保留。技术资料继续写 MobileSAM。目录、API、变量、模型和测试名称属于技术实现，不作为面向用户的宣传描述，见 K02、K04。
- **配置未知**。本地未见聊天界面、文本自由输入及生成回答链路，无法由此判定平台如何归类掩膜和轮廓。标识、备案、审核类目及适用版本另向平台核实，见 P01、P03、P04。
