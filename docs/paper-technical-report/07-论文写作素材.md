## 2. 工程系统论文摘要草稿

**背景：** 局部皮肤照片缺乏可靠的全身位置与尺度信息，通用分割模型输出也不能直接解释为疾病或神经节段。将皮肤区域观察、人体位置确认与参考图谱比较分离，有助于建立可追溯的辅助交互流程。

**目的：** 设计并实现一个支持人工与 AI 辅助标注、人体位置确认及神经皮节参考几何分析的微信小程序系统。

**方法：** 对具有明确授权的正背面 SVG 图谱进行分区数字化与分视图配准，绑定固定人体模板和版本。采用固定预训练 MobileSAM vit_t 接受矩形和点提示，生成多候选像素掩膜；提供局部上下文裁剪、异常提示及人工补充／擦除，保留不连续片区和孔洞。经用户确认的照片几何在原始像素度量中作统一尺度旋转平移，转换到标准人体归一化坐标。通过完整体表包含检查后，使用 Shapely 对同视图标注并集与参考区域求交，报告以标注面积为分母的几何覆盖比例。

**结果：** 当前图谱含正面 27 个标签、背面 30 个标签，共 114 个左右侧区域实例。审计时前端 298 项和 Python 180 项自动测试通过。已有 3 张公开来源照片及 2 张合成图的真实模型实验验证了推理、候选、几何导出及人工修正流程，同时记录了正常皮肤过度分割和低对比度失败。受限 Linux 环境的三个串行输入模型推理为 3.21～4.06 秒，进程峰值 RSS 约 660 MiB；该结果不代表临床性能或并发吞吐。

**结论：** 系统实现了可追溯的交互标注、人工人体放置和参考图谱几何可视化闭环。尚无专家病灶标注、图谱医学审核和独立临床对应验证，不能由现有工程结果推断诊断或医学定位准确率。

摘要中的测试数属于两个测试体系，不建议合并成“478 项医学验证”。篇幅受限时可删去测试数，保留样本限制。

## 3. 可用于方法章节的连续文字

### 3.1 图谱构建

本系统采用 Goran_tek-en 发布的正背面皮肤感觉分区 SVG，并依据原图路径、标签文字及引线建立来源映射。解析嵌套 SVG 变换和填充规则后，将可见填色区域转换为含孔 Polygon/MultiPolygon。针对与目标中性人体轮廓的体型差异，正面和背面分别建立纵向参考行及横向体表区间对应，使用分段线性插值及行间插值映射边界，并通过自适应采样控制近似误差。面部及可见足部采用局部映射增补，保留来源索引、审核状态、派生关系和文件摘要。该处理是参考图谱工程配准，不是对受试者个体神经分布的测量。参数及两种行映射的差异见[02](02-神经参考图谱构建.md)，图 6。

### 3.2 分割与确认

照片先完成格式、体积、解码像素数检查和 EXIF 方向统一。用户矩形／点提示转换到该照片像素空间，局部模式按框和上下文裁剪，并同步平移提示；MobileSAM 对局部输入进行图像编码、提示编码与多候选解码。候选回填到原照片整数像素格，计算面积、框外比例、提示满足程度和碎片特征，用于警告和展示排序，不自动赋予医学正确性。用户可切换候选、补充提示或以画笔修改真实二值 Mask。最终由用户明确确认当前修订。架构与算法见[03](03-AI辅助图像分割.md)，图 3。

### 3.3 几何表示与人体位置

Mask 的前景像素表示为单位正方形，按行合并连续像素后求几何并集，以保存独立片区、孔洞及边缘小区域。照片坐标采用方向统一后的宽高归一化；人工放置时先恢复像素度量，再以整组轮廓中心作相似变换，最后除以人体逻辑画布宽高得到人体坐标。统一变换参数作用于全部外环和内环，显示视口不改变保存几何。确认前验证全部区域被有效体表包含，拒绝跨越身体空隙或覆盖体表孔洞的结果。完整公式见[04](04-坐标转换与几何匹配.md)，图 4。

### 3.4 参考匹配

对每个视图分别将用户标注求并集，避免重复标注造成面积重复计数。相同类型、标签、人体侧别和视图的参考实例先归并，再计算与标注的交集。候选指标为标注落入该参考区域的面积比例；总覆盖率使用全部参考区域并集，未覆盖使用差集。不同标签可能重叠，不能将候选比例直接相加作总概率。结果绑定模板、图谱内容哈希及标注修订；几何变更后旧结果失效。算法见[04](04-坐标转换与几何匹配.md)，图 5。

## 6. 讨论材料：误差链与适用范围

最终结果经过照片分割误差、人工大小／方向／位置误差、源图谱差异、工程配准误差以及二维投影误差。几何算子即使精确，也不会消除前序错误。局部照片没有天然身体侧别、绝对尺度或 T4/T5 标识，人工位置确认是方法核心步骤，不能从标题或流程图中省略。

通用分割模型可能偏向大片一致纹理；裁剪、候选警告和画笔提高可操作性，但尚不等于自动提高病灶真实性。手、足底、后跟和部分头面部缺失应明确呈现为未覆盖，不能补上最近节段。图谱重叠及个体差异使“覆盖最高”只能表示当前几何参考关系。

工程价值是将几何与版本、来源、确认状态联系起来，支持手工回退并暴露未覆盖区域。临床决策价值仍需独立研究，不建议把系统结果作为用药、诊断或神经病损定位依据。
