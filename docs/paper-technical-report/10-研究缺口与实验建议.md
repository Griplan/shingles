# 10 研究缺口与建议实验

本章全部为 **C：研究建议、尚未执行**，除对已有不足的审计。现状有工程实现和有限实验，尚无专家分割真值、独立医学对应标准、图谱专业审核或操作者对照。不得将计划样本量写入当前数据集。

## 1. 优先级 1：专家真值上的分割与交互策略评估

**问题：** 在同等提示与人工操作预算下，局部裁剪、候选警告和真实 Mask 修正是否减少正常皮肤误选，同时保留小病灶？

- 数据：获得授权的去标识化局部皮肤照片，由有资质专业人员逐像素或轮廓标注可见目标；至少两名独立标注者，分歧协商并保留各自结果。疾病标签与可见病灶边界分开记录；需专家明确何种皮疹组成目标。
- 设计：先小规模可行性收集以估计方差，再按病例层面精度／效应目标进行样本量计算；可将 15～30 个独立病例作为**计划中的流程试点**，不能充当充分统计功效保证。至少覆盖光照、肤色、部位、拍摄距离、簇状／离散／低对比度病灶及正常皮肤难例。
- 切分：同一病例、同一就诊及其裁剪／放大图不得跨训练、开发、测试集；测试集在策略定参后冻结。当前通用模型无需训练；若微调，另保留独立患者测试集。
- 基线：固定原始 MobileSAM 全图框选；同提示局部上下文；加当前候选排序；加人工修正。建议逐项消融，不一次更换模型、框大小和操作预算。可增加人工从零标注作为操作成本基线；其他模型需先验证许可证、运行条件和提示公平性。
- 指标：Dice、IoU、像素 Precision/Recall、正常皮肤误选面积、小病灶组件召回、边界距离；同时记录人工笔画／点击数、完整任务时间、失败率、推理延迟。组件匹配和最小可见病灶标准应预注册，不能为结果临时改阈值。
- 统计：每病例汇总，患者层面 bootstrap 置信区间；配对设计检验与多重比较计划事先确定；报告失败，不只报告最佳候选。所有候选平均或人为挑最佳必须区别于实际展示／确认策略。
- 风险：专家之间边界本身可能模糊；图片公开来源偏差、肤色和光照偏差；提示操作者知晓真值造成泄漏；简单裁剪压低误选但增加漏检。
- 条件：**当前不具备专家真值和独立测试集**。必须医学人员参与；数据授权和伦理要求由研究机构确认。

## 2. 优先级 2：独立图谱配准及医学参考对应审核

**问题：** 从源 SVG 到目标人体的边界及标签是否在合理解剖位置？在合法适用范围内，几何输出是否与独立专业判断一致？

- 数据：固定原图、目标模板、完整来源路径表、未覆盖清单及当前114实例；不让评审用本系统输出作为唯一参考答案。
- 设计：至少两名相关专业人员独立审核正背面及左右、面部三叉分区、足部，先定义肩／腋／颈／膝／踝等参考位置与可接受误差。对图谱本身有分歧应记录来源差异，不强迫平均为“真值”。
- 配准对照：当前行映射和局部扩展，与预先规定的简单全局仿射／人工参考映射比较；仅能在合法源图上离线实验，不能将结果自动覆盖现行版本。
- 指标：关键点距离（人体逻辑尺寸或身高比例归一化）、区域边界距离、侧别／标签错误数、超界面积、覆盖遗漏、专家评分和一致性。没有物理标尺不能报告毫米误差。
- 对应测试：另准备经专家确认的人体表面标注及允许的参考标签集合；先定义多标签接受规则、组合标签和未覆盖的处理，再比较系统输出。不可用自己图谱求交生成“医学真值”。
- 样本：优先全量114实例工程审核，再按易错部位分层采样临床／教学场景。具体场景数量根据评审一致性试点决定，不预填准确率。
- 风险：不同皮节图并不完全一致；专家标注依赖同一来源产生循环验证；二维不可见表面和个体差异无法靠脚本消除。
- 条件：当前全部 medical_review_status=pending。必须专业人员参与；通过后需独立有签署、日期、范围的审核记录，不能仅把 JSON 状态改成 approved。

## 3. 优先级 3：多操作者放置一致性与易用性对照

**问题：** AI 辅助流程相较纯人工，是否减少时间／负担，并保持或提高位置与范围一致性？

- 数据：经授权且有明确人体部位、左右与视图上下文的案例；局部照片之外需独立位置参考，不能要求研究者仅凭照片猜绝对位置。
- 设计：同一用户交叉完成手工和 AI 流程，随机／平衡顺序，隔开重复案例以降低记忆；包含新手与专业人员分层。部分案例隔期重复测量操作者内稳定性。
- 基线：当前手工标注；当前完整 AI+人工确认+放置；必要时加入“仅几何贴片但不使用缓存”的工程交互对照，分开研究问题。
- 指标：任务完成率、完整用时、拖动／缩放／旋转及修正次数、中心／面积／角度差、几何重叠、操作者内／间一致性、SUS 或任务负担量表。疾病诊断正确性不能由这些指标替代。
- 参考：若有专家放置参考，先报告其自身一致性；记录2D人体投影的表达限制。角度具周期性，不能直接对179°与−179°按普通差求误差。
- 样本：先做可用性试点以确认任务定义、学习效应和方差，随后按参与者与病例交叉设计计算样本量；不能用一次开发人员演示推论普通用户表现。
- 分析：混合效应或分层配对分析处理参与者、病例及重复测量；预先规定超时、失败、放弃和缺失数据处理。禁止只统计成功完成者。
- 条件：工程流程已具备，当前无系统性参与者记录；需要研究招募、知情同意和相应伦理审查。

## 5. 误差预算与论文表述

总误差不是一个现成可相加的标量。可分别测照片边界误差、人体放置位置／面积误差、图谱映射误差和参考图谱分歧，再用预设扰动敏感性实验观察候选覆盖比例变化；不能把这些数相加构造“总体诊断误差”。建议记录处于多标签边界附近的小位移是否导致排名变化，并报告未覆盖情况。

提交技术系统论文时，可据现有方法、架构和工程实验讨论可实现性。若期刊要求医疗有效性，目前证据不足。最优先三项不是再增加截图，而是**专家分割真值对照、独立图谱／参考对应审核、多操作者放置与易用性研究**。在完成前，摘要与结论必须保留“人工确认”“参考几何”“未临床验证”。
