# AI 会话闲置回收（2026-11-13）

旧机制为创建时设置 expires_at=创建时间+1800秒；客户端轮询该固定时间并主动取消。

新机制：AI_IDLE_SECONDS 配置闲置期限，默认900秒，允许1～86400秒。有效认证访问刷新 last_activity_at 和 expires_at，创建时间另存 created_at。expires_at 保留兼容字段，表示最新闲置截止快照；前端不再按创建响应自行超时取消。访问认证令牌自身期限不变。

运行时复用独占目录锁及30秒扫描，扫描移到线程执行，磁盘清理失败留待下一次扫描。活动推理/画笔处理期间不会被闲置扫描删除。主动删除允许与推理并发：输入已在锁内读入，删除移除文件和索引；迟到结果重新查找失败，不会重建目录。MobileSAM原实现已在finally调用predictor.reset_image释放图片特征，本次未修改模型。模型参数常驻缓存保留，不能把进程RSS未立即下降解释为图片未释放。

停服复用现有systemd五分钟timer，读取刷新后的expires_at。无效快照/未完成目录超过15分钟清理；启动恢复保留last_activity_at，删除过期或损坏目录。旧快照缺少活动时间时使用旧截止时间减当前闲置期限迁移，不延长旧数据存留。单worker目录独占锁阻止多个清理所有者竞争。

放置草稿先复制完整MultiPolygon与孔洞；导航成功本身不再触发删除，目标页面视口与轮廓实际绘制就绪才执行回调。初始化失败不删除。异步删除最多3次，失败间隔500/1000ms，保留清理警告和草稿；回收最终由服务端完成。重复DELETE返回204；存在的会话仍校验照片令牌及用户隔离。删除先完成文件清除再移除索引，磁盘错误不会静默丢失重试索引。
