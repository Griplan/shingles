# 坐标与缩放稳定性验证

## 测试视口

专项测试覆盖：

| 窗口 | Canvas 测试区 |
|---|---|
| 360×780 | 194×460 |
| 390×844 | 224×460 |
| 430×932 | 264×460 |
| 720×760 | 270×640 |
| 800×720 | 320×600 |
| 900×800 | 382×680 |

这些尺寸覆盖窄屏手机、高屏手机、横向工作区和宽屏双栏。

## 缩放锚点

对每个尺寸从初始 viewport 出发，围绕统一 Canvas 锚点连续执行 20 次交替放大、缩小：

```text
1.08, 0.94, 1.08, 0.94, ...
```

每次将锚点从 Canvas 坐标逆变换回归一化坐标，和缩放前锚点比较。六个尺寸的最大误差均小于 `1e-10`。

这证明在现有纯函数路径中，缩放围绕手势中心进行，不改变对应的人体逻辑位置。

## 投影与逆投影

平移后使用：

```text
normalizedToCanvas
→ canvasToNormalized
```

验证 `(0.43, 0.61)` 等逻辑点能够回到原值，误差小于 `1e-10`。人体 PNG、Polygon、神经高亮和 AI 贴片继续共享同一 viewport 投影。

## 容器稳定性

连续缩放测试后：

- `viewportWidth` 保持不变。
- `viewportHeight` 保持不变。
- 页面没有把 `scale` 写回 Canvas 外层宽高。
- 保存的归一化坐标没有修改。

高频平移测试：

- 20 次移动。
- Canvas 边界查询增加 1 次。
- 正式绘制帧增加 1 次。
- 区域点击事件增加 0 次。
- 标注加点事件增加 0 次。

## 未验证

- 手机原生触摸坐标延迟。
- 双指手势中间帧是否连续到肉眼无跳跃。
- 物理折叠屏展开/合上期间的原生 Canvas resize 时序。

以上项目均为 `NOT_RUN`，不能由当前数学测试外推。
