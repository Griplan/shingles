# 滚动与手势隔离

## 页面滚动

首页、人工标注页和放置页均设置：

```json
{
  "disableScroll": true
}
```

页面根节点使用 `100vh`、`overflow:hidden` 和 flex 布局。内容增长只影响独立滚动区，不改变人体工作区的位置。

## 独立结果滚动

- 人工标注页的结果与控制区使用原生 `<scroll-view scroll-y enhanced>`。
- 放置页的大小、方向、错误和确认操作使用原生 `<scroll-view scroll-y enhanced>`。
- 左右神经标签继续使用各自纵向 `scroll-view`。
- 宽屏双栏时右侧结果和控制区独立滚动，左侧人体工作区不重排。

## Canvas 手势

Canvas 使用 `catchtouchmove` 阻止移动事件继续冒泡给页面。

当前手势按模式隔离：

- 浏览/只读模式：单指平移，双指围绕手势中点缩放。
- 人工标注：双指缩放只改变 viewport；单指轻触才尝试添加标注点。
- 放置页人体本身为只读；AI 病灶拖动由独立 `placement-overlay` 处理。
- 信息弹层打开时 Canvas 交互暂停。

## 高频事件

- 手势开始时读取一次 Canvas `boundingClientRect`。
- 后续移动复用该手势内的矩形。
- 每次移动只更新内部 viewport 参数。
- 多个移动事件由已有排队/帧合并机制合并为一次必要绘制。
- 松手后再次安排一次终态绘制。
- 手势期间不重新执行 auto-fit。
- 普通 Canvas 平移不会触发身体区域点击或标注加点。

## 复位

只有明确点击“全身”或等价复位操作，才清除当前手动 viewport 并回到初始全身显示。手势松手不会自动回弹到中央。
