# 几何与显示验证

原侧可见曲线裁片→同侧共享仿射→独立皮肤轮廓包含检查。无平滑、凸包、形态学处理、最近邻分配或标签拆分。每侧矩阵正行列式；全部目标几何有效、无自交、面积非零；两区域内部交叠面积小于1e-10，边线接触不会按面积返回额外候选。后端核对目标与源片变换的对称差，禁止偷偷扩大。

归一化面积占有效显示皮肤：右约6.21%，左约6.25%；精确值和未覆盖MultiPolygon见[evidence/coverage.json](evidence/coverage.json)。这不是实际皮肤物理面积，更不是完整解剖覆盖率。

[左侧区域与真实请求示例](axilla-left-preview.png)、[右侧区域与真实请求示例](axilla-right-preview.png)；[左未覆盖](axilla-left-uncovered.png)、[右未覆盖](axilla-right-uncovered.png)。灰色表示当前图谱未配置，不代表没有感觉神经。

本轮实际病例材料不足，示例病灶明确使用合成Polygon。它确实经FastAPI执行、返回实际相交结果，原始请求/响应见[evidence/real-api-examples.json](evidence/real-api-examples.json)；不能称为真实患者或医学分割验证。预览中的棕线来自该请求几何，T1/T2颜色来自运行同一份图谱，没有另画展示版边界。

多片、孔洞在请求与V4计算中保留；当前手动UI只提供外环逐点圈选，未新增孔洞绘制工具。前端共享Canvas/高亮沿用同一geometry，放大/复位只变视口；原P6校验与调度模块没有改动。

这些预览为实际SVG/JSON离线渲染，已目检，不是微信运行截图。临床真值、医学误差、皮节个体差异、抬臂皮肤形变均未验证；不能由仿射拟合残差推导临床准确性。
