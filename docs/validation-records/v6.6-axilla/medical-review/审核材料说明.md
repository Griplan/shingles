# V6.6.1 腋下参考图谱医学审核包

本轮交付的是**可交给医学人员逐项审阅的资料包**。没有新增可计算神经多边形；左右运行图谱仍为0区域，保留 `ATLAS_NOT_READY`。

## 审核人员按此顺序查看

1. [图04：模板改良候选与定位缺口](figures/04-模板改良候选与定位缺口.png)：先决定现有裁窗能否支持限定范围，还是需要完整肩部/肘部/胸壁标志的新模板。
2. [图01：左腋下待审核参考图](figures/01-左腋下待审核参考图.png) 与 [图02：右腋下待审核参考图](figures/02-右腋下待审核参考图.png)：逐侧核对朝向、五个观察区、检查点定位与缺失面。两侧都要看，不能只审一侧后镜像通过。
3. [图03：Goran九路径源图对照](figures/03-Goran九路径源图对照.png) 和 [原路径表](原始Goran路径对应表.md)：判断哪些源曲线确实对应同一皮肤表面、哪些不能跨姿态移植。
4. [医学依据清单](医学依据清单.md)、[已知边界与不确定区域](已知边界与不确定区域清单.md)，然后填写 [医学审核表](医学审核表.md) / [CSV](医学审核表.csv)。

四张图都有可编辑SVG，同名位于figures目录。真正用于勾画的400×360空边界底板在 [左侧](review-draft/left-annotation-sheet.svg) / [右侧](review-draft/right-annotation-sheet.svg)。草稿中不预填神经区域，避免把软件建议误当成专家结论。

## 现在已知与仍缺少什么

| 问题 | 本轮结论 |
|---|---|
| 有哪些有来源的皮节信息？ | Goran T1/T2/T3胸背色带与内臂T1、T2、T1/T2组合条带的9条原路径；标准资料的T1/T2/T3关键检查点定义。源图曲线可以复现，点定义可以追溯 |
| 能否据此完成抬臂腋窝分区？ | 不能。原图垂臂姿态没有展开完整腋窝底面；尚无目标同表面控制点、闭合边界和医审签署 |
| 肩部缺失是否有影响？ | 有，限制姿态判断与稳定定位；只补画外形不解决证据问题。已提供保留旧模板的审核版A及扩展取景设计B，未覆盖现有模板 |
| 是否将肋间臂神经当成T2？ | 没有。M3/M4仅用于概念核对，没有转成运行神经区域 |
| 医生需要提供什么？ | 先判断模板可用性，再逐侧确认关键点、褶线、源图对应面；提交有来源、许可、签署、明确不确定/排除范围的边界文件，或否决/要求更完整资料 |

O1–O5 是观察区域，不是五块皮节。`K2?` 是待定位问题标记，不是医学坐标。红网纹提示Goran未展开表面，精确缺失面的目标几何仍未知。橙色斜线代表目标皮节边界尚未建立，不代表皮肤没有神经。
