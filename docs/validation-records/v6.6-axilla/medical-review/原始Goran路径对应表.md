## 变换、覆盖与左右实例

- 原 XML 未发现 `mask`、`clipPath`、`use`；没有忽略隐藏的 SVG 遮罩。实际父级矩阵已逐元素累计，写入 JSON（例如 front-p1 的平移为约20.32、4）。
- 9个实际元素都使用 `fill-rule:evenodd`，解析复用现有填充规则处理，证据与突出显示一并保留该规则。
- 按实际颜色路径绘制顺序扣除后画的皮节填充，排除另置的头部插图。以0.02 SVG单位曲线采样记录 raw 与 paint-visible 两份几何、面积、部件数及包围盒；没有修改源曲线控制点。
- 此处 visible 指**颜色层之间的可见投影**，不包含生物学三维遮挡反演。阴影/线稿只保留在源图上下文中，不被解释为额外神经区域。
- 前图屏幕左为人体右、背图屏幕左为人体左。跨中线色带的左右面积分别记录；中线分拆只是源图实例核对，不是新神经边界。源图各半都有实际几何，不能用一侧镜像替代另一侧。
- 独立模板是抬臂近景，源图是垂臂正背面：同一标签、同一人体侧不等于同一二维坐标。无法据此给出目标缺失面的面积百分比。
