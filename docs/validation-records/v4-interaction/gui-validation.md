## 失败、异常和限制（保留）

1. 首轮原生WXML编译因`&amp;&amp;`失败，后改为原生表达式`&&`通过；详见native-compile-first.txt和native-compile-final.txt。初次scope控件受默认按钮宽度影响，改为76px紧凑按钮，390画面复核通过。WXSS标签/属性选择器警告改用class处理，最终原生编译通过。
2. 多次热重载、换机型和后台操作后出现`noWindowsAvailable`、截图状态栏时间与AX树不一致。320画面还出现Canvas上移覆盖上方控件。加入局部定位/溢出约束后，用户恢复前台，并通过实际上下滚动观察到正常居中画面；不足以证明已定位或根治所有合成/刷新异常。
3. 320缓存重入出现结果页空白及上一页画布残影；复核页提示“页面未能打开，标注已保留，请再试一次”。未将其归因为后端或匹配公式。切机型重启后可重新进入首页、选择、标注，但尚未完成同条件缓存重入复测。
4. 用户再次确认已恢复前台后继续操作：375×667（iPhone6/7/8）进入人体选择、从列表选择胸部、进入标注页成功；但截图反复返回小尺寸倾斜窗口，无法可靠据此确定画点位置，因此没有盲点合成病灶或宣称375结果页通过。Raise未可靠解决；可选launch_app接口在当前运行时不可用。430实测未运行。
