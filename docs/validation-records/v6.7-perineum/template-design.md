# 中性会阴模板设计

## 观察方向

- 顶部标记“前侧”。
- 底部标记“后侧 · 肛门区居中”。
- 画面左侧标记为人体解剖左，画面右侧标记为人体解剖右。
- 中央为中性后下方会阴示意，周边保留内侧大腿上下文。

该视图不是完整会阴环周。用户看到的是用于二维圈选和空间匹配的单一示意面。

## 几何

- 模板：`neutral-perineum-overview-v1 / 1.0.0`
- 几何：`neutral-perineum-skin-v1`
- 区域集：`neutral-perineum-ui-v1`
- 逻辑画布：400 × 560
- 坐标：左上原点、x 向右、y 向下、归一化 0–1
- PNG：800 × 1120

皮肤外缘由项目内三次曲线采样后闭合。中央肛门开口是 `BodyGeometry` 中的真实孔洞；它不参与有效皮肤标注，也不能被区域并集填实。

## 中性设计

模板不绘制具体男女外生殖器，避免从单一性别图直接推断另一性别。中央前侧/泌尿生殖面保持为“模拟未定区”，因为本轮没有足够材料建立该表面的医学分区。

内侧大腿只作为定位上下文，并在图上标注“非独立皮节”。它们仍属于当前模拟皮肤面，几何计算会将其纳入 S2/S3 等示意区域。

## 已知限制

- 二维后下方观察，不代表完整环周。
- 模板比例和皮肤外形是项目原创示意，没有与患者照片自动配准。
- 肛门开口只表示图中可见孔洞，不包含肛管或深部结构。
- 该视图不支持 AI 照片上传或自动放置。
- 模板可标注和模拟匹配，不代表医学边界或解剖配准已经审核。
