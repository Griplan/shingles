## 几何检查

- 所有区域均非空、有效且位于皮肤轮廓内。
- 并集覆盖全部有效皮肤。
- 区域间正面积重叠为 0。
- 肛门开口保持孔洞，中心点不属于有效皮肤。
- S2、S3、S4、S5、UNDEFINED 的人工参考点分别返回预期模拟标签。
- 完整皮肤请求返回 5 个模拟候选且总覆盖为 1。
- 多片、孔洞、重复病灶并集和共享边界由真实 API 测试覆盖。
- 人体外标注、自交、旧版本和发布环境门禁均明确拒绝。
