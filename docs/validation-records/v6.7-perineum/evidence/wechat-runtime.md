# V6.7 微信开发者工具运行证据

## 环境

- 日期：2026-11-07
- 工具：微信开发者工具 Stable 2.01.2510290
- 基础库：3.17.4
- 小程序：Shingles
- 后端：`DERMATOME_ENV=test ENABLE_REFERENCE_MATCHING=1`
- 接口：`http://127.0.0.1:8000/api/v1/evaluate`
- 健康接口：`GET /api/v1/health` 返回 `status=ok`

## 实际流程

1. 从项目首页进入人体模型。
2. 打开特殊部位，选择会阴区域。
3. 在会阴 Canvas 有效皮肤范围取 3 点。
4. 闭合三角形并完成标注复核。
5. 点击模拟区域匹配，确认请求到达当前后端。
6. 核对实际返回标签、几何覆盖比例和免责声明。
7. 在 428 像素宽设备验证单标签、显示全部、放大和复位。
8. 在 320、375、430 像素宽设备分别重复取点、闭合、复核和真实匹配。
