# 坐标与放置

## 坐标空间

完整人体人工标注和 AI 放置统一使用 `body_template_normalized_v1`。正面与背面各自使用独立模板版本、几何文件和坐标空间；相同 `[0,1]` 数值不能跨面直接复用。

照片在帧选、Mask 和放置前仍使用 `photo_oriented_normalized_v1`。照片宽高比和人体逻辑画布宽高比分别参与相似变换，不使用两个归一化轴的非等比缩放。EXIF 修正、图片缩放和多边形/孔洞保留沿用 P8/P8.1、V5.1 和 V5.3 实现。

## 浏览与编辑

完整人体 Canvas 支持只读相机平移和双指缩放。相机变换只改变显示视口：

```text
screen = viewport · body_normalized
```

打开标注、保存点位、窗口 resize、折叠屏重排或返回全身时，人体归一化 Polygon 不变。标注页的浏览手势不会产生区域点击或新顶点；标注模式的单点输入被隔离。

## 放置草稿

AI 放置组件在交互中只保留：

- `translation`
- `scale`
- `rotationDegrees`
- 当前目标人体模板/视图

拖动使用缓存贴片的仿射预览和单帧合并；触摸移动不重建完整 MultiPolygon，也不调用后端。结束调整时才用原始照片几何计算一次正式人体变换并执行本地完整人体校验。

## 原始几何与有效几何

最终确认时区分：

- `rawGeometry`：由原始照片 MultiPolygon 和当前变换得到的可编辑几何，允许暂时穿过人体外空白。
- `geometry`：最终保存和 V4 匹配使用的有效人体几何。
- `clippedFromGeometry`：用户确认人体交集前的原始变换结果。
- `clip.outsideAreaRatio`：被人体外轮廓排除的面积比例。

完全位于人体内时，两者相同。部分越界时，前端只调用一次 `POST /api/v1/evaluate/body-intersection`。用户确认交集后：

1. `rawGeometry` 保持为继续调整的来源。
2. `geometry` 替换为精确的人体交集。
3. 交集继续保留 MultiPolygon 片区和孔洞。
4. 下一次平移、缩放或旋转会清除旧裁剪来源和比例，重新执行完整校验。

完全位于人体外时返回错误，不能保存。边界检查结果前后不一致时采用失败关闭，不制造极小裁剪。

## 正反面与特殊部位

放置页允许切换 front/back，切换时在目标模板建立新的初始位置，但不推断病灶真实解剖面。现实跨前后面的病灶由用户分别标注两面。

脚底、腋下和会阴使用各自 viewId、模板和 atlas。V7.0 不把完整人体 Polygon 自动投影到这些特殊部位，也不反向迁移特殊部位坐标。
