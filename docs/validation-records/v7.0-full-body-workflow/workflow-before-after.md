# 流程改造前后

| 环节 | V7.0 之前 | V7.0 |
| --- | --- | --- |
| 首页 | 先进入部位选择页面 | 直接进入完整人体页面 |
| 手动标注入口 | 必须先选择当前视图中的部位 | 无部位也可直接开始 |
| 区域字段 | `regionId` 参与入口、会话和局部限制 | 仅保留为可选快捷定位/初始聚焦提示 |
| 跨区病灶 | 容易受入口粗区域限制 | 以完整人体轮廓校验，可跨腹部、腹股沟和大腿等旧边界 |
| AI 上传 | 依赖预选部位 | 照片准备和分割不读取部位 |
| AI 初始位置 | 固定在预选部位附近 | 无部位时使用当前视图合理初始位置；可切换正背面 |
| 放置范围 | 局部视图约束明显 | 可在完整人体任意有效位置自由移动 |
| 越界处理 | 通常直接拒绝或局限在预选区域 | 最终一次性精确交集；用户确认后保存有效部分 |
| 匹配入口 | 从标注结果进入 | 完整人体主页提供统一“神经匹配”入口，标注复核页仍可计算 |
| 匹配筛选 | 可能受入口区域上下文影响 | 只使用最终保存几何和实际 front/back 视图 |
| 特殊部位 | 独立入口和坐标 | 保持不变，仍与完整人体隔离 |

旧入口的被移除部分是“强制选择”，不是所有区域导航能力。用户仍可点击区域快捷放大，但它不能再决定最终可放置范围或神经候选。

完整流程：

1. 打开小程序，默认显示完整正面人体。
2. 切换正面/背面，单指或双指浏览。
3. 直接进入手动标注，以完整人体逻辑坐标取点和闭合；或直接上传照片进入 AI 分割。
4. AI 用户确认 Mask 后生成自包含 MultiPolygon 草稿并打开完整人体放置。
5. 自由拖动、缩放、旋转；过程中不调用后端几何匹配。
6. 最终确认时检查完整人体轮廓。部分越界由用户决定是否使用精确交集。
7. 保存后立即使用最终几何执行参考匹配和高亮。

特殊部位继续从“特殊部位”入口打开，各自使用独立模板、会话和匹配身份。
