# 历史数据兼容

## 会话结构

V2 会话的 `schemaVersion` 没有升级。`regionId` 和 `entryRegionId` 改为可空的可选导航提示；旧数据中的字符串值仍能读取。非空值只用于：

- 主页面的快捷局部聚焦；
- 放置页面的初始视觉位置；
- 返回结果后的视口提示。

它们不再参与：

- 完整人体轮廓合法性判断；
- 最终放置范围限制；
- V2 保存权限；
- V4 图谱候选筛选。

只有空占位草稿可以更新新的可选提示。已经包含顶点的手工草稿、另一面的草稿和已确认 AI 标注不会被新入口自动覆盖或清空。

## 旧标注

旧手工 Polygon 和旧 AI 放置结果继续保持原 view、坐标、模板版本、图谱身份和 revision。读取时会继续检查模板、geometry、region set 和会话修订；无法可靠解释的版本差异仍明确拒绝，不自动迁移或猜测坐标。

保存的 AI 结果仍包含确认照片摘要、原始变换、片区、孔洞和已确认来源。历史结果没有新增字段时仍按原语义处理；新字段 `clippedFromGeometry` 和 `clip` 为可选，不改变未裁剪数据。

## 特殊部位

脚底、腋下、会阴和旧导航数据没有迁移到 front/back。特殊部位会话继续独立保存，现有路由和回退规则保持不变。

## 兼容边界

本轮不提供旧粗部位坐标到新全身模板的自动转换，因为模板版本相同且原始坐标本就是完整人体坐标；旧 `regionId` 只是上下文标签。若历史会话的模板、几何或区域配置确实不一致，仍保留原数据并拒绝静默重解释。
