# 匹配验证

## 匹配输入

V7.0 不修改 V4 Shapely 交集、覆盖比例或候选排序。变化只在调用方：

- 使用最终保存的 `geometry`；
- `view` 必须来自实际保存的 front/back；
- 不再按入口 `regionId` 过滤；
- 把同一视图的全部已确认病灶交给原 V4 合并计算。

部分越界用户确认有效交集后，交集成为唯一的正式匹配几何。原始可编辑变换只保留在 AI 来源信息中，不进入神经候选筛选。

## 主入口

完整人体页面在存在已确认标注时启用“神经匹配”。入口会读取 V2 权威会话，拒绝未闭合草稿，切换到复核状态，再打开原结果页。没有已确认标注时按钮保持禁用。

结果页继续使用现有：

- 单区/全部显示；
- 覆盖比例和未覆盖比例；
- 多候选；
- 左右解剖侧；
- 高亮与标签切换；
- 结果失效和重新计算。

## 几何回归

自动测试覆盖：

- 跨粗区域边界的手工多边形；
- 最终几何完全位于人体内；
- 部分越界并返回精确 MultiPolygon；
- 完全越界拒绝；
- 多片和孔洞保留；
- 正背面坐标隔离；
- 自交和超限拒绝；
- 保存后的有效几何进入 `/evaluate`；
- 旧身份/版本不一致拒绝。

新增 `/api/v1/evaluate/body-intersection` 与 `/evaluate` 使用同一 reference-matching 门禁：本地 development/test，或已配置 `API_ACCESS_SHA256` 的 controlled 测试服务。两者还共用 2 MiB 实际正文上限；交集接口最大接收 20,000 个轮廓顶点。它不运行 MobileSAM，也不查询图谱。

## 医学边界

该文档只验证二维几何与交互一致性。当前参考图谱的医学审核状态保持原值，几何覆盖比例不是诊断概率，V7.0 没有生成新的医学皮节边界。
