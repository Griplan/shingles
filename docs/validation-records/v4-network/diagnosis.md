# V4 本地计算连接失败排查（2026-10-26）

用户实际结果页提示“无法连接后端或请求超时”。只读查看当前微信工具Console，确认原始错误为：

`http://127.0.0.1:8000 不在以下 request 合法域名列表中`

这次请求被开发工具合法域名校验阻断，不是已证实的后端超时。项目及本机私有配置的urlCheck均为true。Uvicorn仍监听127.0.0.1:8000；允许本机连接后，health及自带TEST合成请求均HTTP200。沙箱中的初次curl失败是执行环境网络隔离，未据此误判后端停止。

修改services/api.ts，按wx.request fail.errMsg区分域名拦截、超时与其他连接错误。只解析已知错误类别，不展示或记录原始请求/平台错误全文。未修改人体、图谱、后端或项目安全开关。未重启项目或主动重提交用户现有标注。

测试：npm test --prefix miniprogram，144/144 PASSED；npm run typecheck --prefix miniprogram，PASSED。日志在同目录frontend.txt与typecheck.txt。新增测试通过真实API封装验证域名错误不会再被写成超时。

本地模拟器调试127.0.0.1需由开发者临时允许跳过请求域名校验；设置入口通常为“详情→本地设置→不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”。该选项降低当前开发会话的网络校验，不能作为上线配置。也可保持校验并配置已登记的有效HTTPS后端域名。正式地址配置后恢复校验。本轮只提供说明，没有自动改变此开关。

此前README提供HTTP回环地址但未说明该地址会被当前urlCheck=true阻断，联调说明不完整，现已补充。平台默认门禁与医学审核状态不变。用户启用本地调试选项后的实际小程序请求尚未验收，不提前记通过。
