# 尺寸事件与生命周期

复用页面与组件现有 resize 生命周期。页面只更新轻量布局字段与版本号；不重进会话、不提交匹配或推理。组件以 `wx.nextTick` 合并同一轮重测，查询真实 Canvas 节点和尺寸，丢弃旧回调；画布与图片资源在同一节点上复用。页面隐藏或组件卸载后，旧的测量、触摸或绘制结果不能提交。

人体、局部和照片组件从尺寸失效起暂停坐标输入，直到取得新视口；照片和人体放置检查相应的布局版本。贴片通过已有局部预览恢复，未完成调整回滚至上一次完成的变换，复用上次几何引用，resize 不运行完整合法性检查。

自动化覆盖连续尺寸变化、触摸查询迟到、局部画布待绘制帧取消和卸载后的回调。手机长时间反复折叠的内存曲线未测；不能以自动化引用与生命周期断言推断真机没有泄漏。
