# AI 与特殊部位

- 照片工作页宽屏将原照片、框、点与 Mask 放在左侧，上传、候选、调整和确认在右侧。选择文件、EXIF、高清缩图、上传与后端确认流程沿用 P8/P8.1。尺寸变化不重复上传或推理。当前项目照片显示仍是等比适配，未新增手势放大功能。
- AI 放置继续以人体视口投影同一份多片及孔洞几何。完成的平移、大小和角度保留。调整中改变窗口会取消该次操作，确认时仍走既有完整校验与保存。
- 双侧脚底、双侧腋下和会阴共用局部页面布局；每个模板继续按自身比例显示。右栏复用各视图候选、显示全部、放大、复位及圈选操作。腋下与会阴的模拟状态和未医审提示仍保留。

真机最小复测：窄屏圈选后展开并再折回，检查同一病灶和标签；对 AI 结果保留框与 Mask，再做一次放置、旋转并切换尺寸；分别打开脚底、腋下和会阴，检查候选及右栏滚动；在矮屏和系统键盘弹出时检查底部按钮可达。使用合成或公开授权测试图。
