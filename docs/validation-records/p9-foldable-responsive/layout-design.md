# 布局和断点

| 逻辑窗口 | 预期 |
| --- | --- |
| 360×780、390×844、430×932 | 原有手机单栏，人体结果保留两侧轨道 |
| 540×720 | 加宽单栏，限制文字和内容宽度 |
| 720×760、800×720、900×800 | 双栏，左侧画布，右侧操作、标注筛选与候选 |
| 800×480 | 单栏紧凑回退，操作区可由页面滚动到达 |
| 390×460 | 矮窗口依旧使用单栏；以容器实际测量为准 |

共享 WXSS 以媒体查询驱动，避免 JS 与 CSS 采用不同断点。680 px 时，减去边距与栏间距后仍能为侧栏留至少 244 px，画布约 388 px；较宽时按约 5:3 分配，整体内容上限 1120 px。520 px 高度门槛给主画布和右栏预留至少约 310 px，较矮窗口交给页面纵向滚动。侧栏独立滚动，常用操作排在可能较长的候选列表之前。宽屏隐藏旧轨道；两种呈现都用相同的候选 ID 和点击处理函数。

页面高度随可用窗口变化，保留 `env(safe-area-inset-bottom)`，宽屏与横向紧凑窗口考虑横向安全边距。导航高度由微信管理。窗口矩阵是测试输入及预期，未逐一在微信模拟器渲染。物理设备键盘与安全区行为需单独验收。

旋转和可调整窗口采用微信的 `pageOrientation: auto` 和 `resizable: true`，依据[腾讯官方显示区域说明](https://intl.cloud.tencent.com/ind/document/product/1219/61744)。
