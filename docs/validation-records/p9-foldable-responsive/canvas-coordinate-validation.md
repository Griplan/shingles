# 画布坐标验证

人体仍用 `fitViewport`、`focusViewport`、`reframeViewport` 和同一个归一化坐标逆变换；放大区域与中心仍绑定原逻辑坐标。AI 放置到结果页的既有视口交接仍保持 CSS 比例和解剖中心。照片及 Mask 用同一个 `fitPhoto` 显示矩形。

微信 Canvas 节点经选择器读取真实 CSS 宽高；backing store 使用共享尺寸预算，DPR 不超过 3，每轴不超过 3072 px、面积不超过 400 万像素。DPR 只进入绘制，不参与触摸归一化。接触坐标仍以 CSS px 为单位。

新增人体画布模拟矩阵测试，以文档窗口作为外部场景，给组件注入不同实测容器的替身输入。覆盖全套建议尺寸、矮窗和返回窄屏；验证固定逻辑点的正反投影误差小于 1e-12，局部中心回到新容器中心，DPR 上限成立。照片组件校验每次变形后原图与 Mask 绘制参数逐项相同。结果页测试比较窗口变化前后会话序列化，结果完全一致。

这些是生产 TypeScript 在 Canvas 调用记录器上的自动测试。真实折叠屏触摸映射未运行。
