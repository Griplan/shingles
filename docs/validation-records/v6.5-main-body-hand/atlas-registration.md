# 四个主人体手表面独立配准

## 坐标与版本

人体图片、400×900 逻辑画布、归一化原点和左右约定不变。正面人体左手在屏幕右，背面人体左手在屏幕左。源图与目标的四只手分别取自身几何，未用镜像一只手作为另一只手数据。

新图谱 `goran-2022-commons-template4-preview.3`；模板 `commons-neutral-v1 / 4.0.1`；有效轮廓 `commons-blank-cc0-hands-v2`。模板 patch 版本变化的原因是**有效手指间隙发生修正**，不是更换图片。UI regionSet 保持配置2，绑定新的 geometryId。旧 `preview.2` 与 `commons-template4.json` 不改。

## 方法与限制

1. 源图源 y=440 以下的手表面，分别与目标旧图谱腕部端点衔接（正面 y=440.1111111111、背面 y=439.6666666667）。实际 source path 超出该局部域的部分不纳入本轮。
2. 目标旧蒙版用 3倍栅格和形态处理，部分狭窄指缝被填实。依据原 CC0 SVG 手指路径 front path4036/4119、back path4023/3979，以及拇指路径4024/4123/4021/4001扣除指缝。源 SVG 累积变换与嵌套 viewBox 均处理，曲线采样0.02逻辑单位；不改 PNG、SVG、手腕以上轮廓。
3. 每手11个边界对应：桡侧腕、拇指尖、虎口、食指尖、食中指缝、中指尖、中环指缝、环指尖、环小指缝、小指尖、尺侧腕。实际轮廓极值定位后逐手查看；配对边界按弧长采样。
4. 使用正则化薄板样条（单位/100，正则1e-4），边界点采用准确的成对边界插值。反射仅为求解器数值条件统一，之后逆转回本手坐标，绝不跨侧复制。
5. 源曲线采样0.12源单位，内部边采样0.1源单位。所有变换片区先验证有效；不使用buffer修复或凸包。不连续片区/孔洞按原结构变换。
6. 记录变换超出目标皮肤的面积后与目标皮肤相交；继承区域不改，新区仅补未覆盖手面。少量采样交叠按真实绘制顺序消解。最终拓扑保持简化上限0.002逻辑单位，单片结构变化或Hausdorff超限即保留原采样。未覆盖缝隙保留，不就近归区。

初期公共三角剖分、均值坐标、无正则TPS出现拓扑/局部折叠问题，未投入运行；日志与试验图保留。圆盘中介法虽有效但边界角折不合理，同样未采用。

最终四手1源单位网格共16690点的有限差分检查没有负Jacobian；最小值分别0.13991、0.05799、0.07565、0.06207。**离散网格不是连续可逆性证明，也不是医学配准误差测量**。边界附近仍有4个采样点轻微超域；逐path真实超出面积最大约0.276逻辑平方单位，显式裁切并保留缺口。原源描边缝、源目标姿势差异与腕部衔接曲率差异需要专家复核。
