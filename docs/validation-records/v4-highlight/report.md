# V4 彩色参考区域高亮专项检查（2026-10-26）

## 原因与实现核对

- result.calculate先清空selected；sync只取coverage.candidates中匹配selected的候选。未选择时ids为空，传给Canvas的atlas.regions也是空数组，因此没有彩色填充，放大按钮禁用。这与用户截图及当前实际状态一致。
- “当前视图汇总/标注1/标注2”用于切换统计范围，chooseScope同样清空selected；它们不直接选参考候选。
- 真正的高亮入口是候选列表中的神经标签/侧别按钮，bindtap=chooseCandidate。选中后按后端region_ids取同版、同面的实际ATLAS_REGIONS。
- body-canvas的atlas属性变化触发刷新。原drawBody在人体图后调用drawAtlas，再画drawLesions；atlas-render按真实多片/孔洞归一化路径填充，透明度0.29，并检查模板/视图/版本。没有发现以包围盒代替参考区域或参考层被人体底图覆盖的问题。
