# 几何等价与正确性

## 两层校验

完整拓扑校验用于所有不可信输入：

- 照片确认结果第一次进入。
- 指纹不匹配或来源几何被修改。
- 后端返回的人体交集几何。
- 重新编辑保存几何时，构造出的当前变换结果不是已知可信来源。

可信快速校验用于已通过完整校验的冻结 `PreparedPhotoGeometry`：

- 只允许正数等比缩放、旋转和平移后的结果。
- 仍检查人体所有正背面轮廓和人体孔洞。
- 仍使用精确点包含、线段与人体边界交点、完整填充面和人体孔洞穿越判断。
- 不跳过最终人体边界约束。

## 保留内容

- 多个不连续病灶片区保持独立。
- 孔洞继续按孔洞处理，不转成凸包或实心外轮廓。
- 小片区不因性能优化被删除。
- 照片坐标和人体坐标继续是两个显式空间。
- 变换顺序保持“照片像素度量 → 等比缩放 → 旋转 → 平移 → 人体归一化”。
- 最终确认仍重新计算并比较预览几何。

## 回归覆盖

- 自交、退化边、重复点、非法面积。
- 孔洞越界、孔洞重叠、孔洞接触导致填充断开。
- 独立片区重叠和片区共用边。
- 人体空白、手臂与躯干间隙、双腿间隙和人体孔洞。
- 低缩放、高缩放、正负角度、横竖照片和不同画布尺寸。
- 真实 389 片区、301 孔洞样本。
- 500/1000/2000 孔洞性能样本。

真实复杂样本在快速和完整人体校验下均返回 `ok=true`，片区与孔洞数量不变。有效与人体外场景的快速/完整结果逐项一致。非法孔洞和自交仍由完整入口拒绝。

`preparedPhotoMatchesSource()` 使用对象身份加内容指纹。复制或序列化后的几何不能冒充可信来源；修改 Mask 摘要、候选、尺寸或顶点会使缓存失效。
