# V3.1 面部与可见足部图谱实施说明

本文记录数据契约、来源和复现方法；唯一进度台账仍为 [task.md](../task.md)。

## 版本与边界

当前图谱为 `goran-2022-commons-template4-preview.2`，父版本 `preview.1` 的十个文件原字节保留。人体仍为 `commons-neutral-v1 / 4.0.0`，geometry 为 `commons-blank-cc0-v1`，逻辑尺寸 400×900，归一化坐标、正背面资源、命中轮廓及 V2 会话契约不变。没有病灶读取、交集、候选排序或诊断；`mappingEnabled=false`、`medicalReviewStatus=pending`。

## 缺失原因与本次覆盖

旧版主动排除了三叉神经路径：主面部路径存在，但 source-map 中没有启用标签；旧类型只表达脊神经及组合标签。没有发现只允许 C/T/L/S 的标签正则在拒绝 V 标签。排序表缺少 V 顺序已补齐。

旧版足部在源 y=842、目标 y=820 处明确截止，纯足部路径被登记为未配置；并非小面积简化删除，亦非前端已经有数据却隐藏。

## 局部配准与几何保护

制作输入为 [local-registration.json](../data/atlas/goran-2022-preview-v2/local-registration.json)。源 SVG 解析嵌套变换、实际填充及绘制覆盖顺序，排除独立头侧插图。目标 SVG 的嵌套 viewBox 平移也纳入计算。

面部使用眼角、鼻尖/鼻翼、嘴唇及下颌的分行、分段单调对应。源眼高 66.5→目标 102，鼻部 90.5→123，口部 104→135，下颌 129.386→160.6；各行分别记录左右 x 锚点，不使用整体矩形拉伸或上中下三条横带。插值先在对应控制行之间插值 x 锚点，再映射位置，避免局部折叠。

目标头发闭合原路径 path4145、头发以上范围、保守耳部窗口、可见眼球开口及闭口缝隙显式排除。这些是“不支持表面”的显示掩膜，不是新增神经边界；耳道、口腔内部、复杂耳周和头侧不宣称覆盖。细小颞侧片区来自源矢量，保留其多片拓扑，需医审复核。与父版 C2/C3 的冲突从新片区排除并报告，没有静默覆盖父版。

正面左右足各自根据原图与目标的足背轮廓配准。踝线 842→820，之后源 860/890/916/934/945.5 对应目标 831/843/854/865/869。每足独立采样轮廓，迁移源 L4/L5/S1 边界，不从小腿外推、不平均分趾。源与目标趾间空白按各自轮廓保留。同标签在踝线相接的面做合法并集，保留 ID 和旧标签点；独立检查原几何无面积丢失、踝线上方不变。

新增几何不使用面积阈值删碎片，也不进行简化；自适应采样目标平直误差 0.001 逻辑像素。没有 buffer/make_valid/凸包修补。裁切前体外面积、明确表面排除、父版冲突、保留面积分别记录于 [局部报告](../data/atlas/goran-2022-preview-v2/local-registration-report.json)，不能以裁切后合法代替解剖配准。sourceVisibleAreaBeforeSideSplit 是分侧前的源面积，双侧面部报告会重复引用该面积，不能相加当成独立源面积。

原有 106 实例中，除正面 L4/L5 四实例追加足部并集外，其余 102 实例几何完全不变。父版已有的微小采样重叠约正面 0.412、背面 0.430 逻辑像素²仍报告，未宣传为绝对无缝。技术几何通过不等于医学正确。

## 单一数据源与复现

权威目录为 `data/atlas/goran-2022-preview-v2/`。父版原输出作为不可变继承输入，由十文件 SHA256 固定；原 SVG 与目标 SVG 亦校验指纹。`source-map.json`、`local-registration.json` 为新增制作输入，旧 registration 用于说明继承。生成器只写新目录，禁止为了重建新版本覆盖父版。

在项目根目录执行：

```sh
backend/.venv/bin/python scripts/prepare_atlas_extensions.py
python3 scripts/sync_atlas.py
backend/.venv/bin/python scripts/check_preview_atlas.py
backend/.venv/bin/python scripts/test_atlas_extensions.py
backend/.venv/bin/python scripts/test_atlas_geometry.py
python3 scripts/sync_atlas.py --check
npm run typecheck --prefix miniprogram
npm test --prefix miniprogram
backend/.venv/bin/python scripts/preview_atlas_extensions.py
```

front/back、coverage、local-registration-report 为确定性派生物。同步校验覆盖七项输入（含新增局部配置），包内 atlas.generated.ts 不手改。可选 PNG 证据由已有 Sharp 渲染 SVG，不增加小程序依赖。

## 交互与验证依据

图谱测试页新增分组、三分支直接选择、面部/双足放大；保留原生分区列表、左右筛选、标签和全身复位。局部放大只改变视口，不改归一化数据；全身时仅抑制过密小区域文字，不隐藏几何。背面无三叉分支时明确提示，无脚部对应时解释足底与足跟差别。所有入口和动作继续受 develop 环境限制；trial/release/未知环境均默认拒绝。
