# 身体粗区域约定（V1.6）

这是产品交互分区，不能解释为医学皮节或神经支配。进度和实际测试只见[task.md](../task.md)。

## 原因核查

| 问题 | 实际实现与结论 |
| --- | --- |
| 高亮画什么 | render.ts将selected.outline作为闭合路径填色/描边，再裁切到源人体轮廓；未画bounds |
| 点击判定什么 | probeTouch统一逆变换和人体门控，body-hit-test将outline转同一逻辑单位做点包含；bounds仅预筛 |
| 放大是否误共用粗范围 | 放大使用bounds，职责原本已分开；错误是outline本身过粗，不是三用途混用 |
| 胸/上肢是否重叠 | 原四点梯形实质进入肩/上臂，与上肢存在面积重叠；背面同类问题，详见几何日志 |
| 是否整图错位 | 原SVG及1200×2700 PNG按同一400×900画布匹配。未发现整体变换错位；局部分区过宽与边界缺少腋下转折，不应靠移动图片修复 |

## 三种数据职责

- outline：regionGeometry。归一化不可变顶点，隐式闭合。唯一高亮及最终命中数据源，不每次点击重采样。
- bounds：focusBounds。由outline包围盒加0.015横/0.012纵归一化留白生成，限于画布；可以包含未选中的手臂视野，不可拿来填色或最终命中。
- hitOutline/visual.outline：bodyOutline。同源整体轮廓分别用于点击门控和绘图clip，不包含内部身体分区语义。

源SVG是完整人体线稿，存在肩臂和腋线细节，但不是一套封闭的胸/上肢分区路径；没有直接把某条SVG细节当作完整区域。当前区域按真实源图和逻辑坐标网格人工选点，在配置初始化时一次转成[0,1]。源码编辑使用逻辑单位只是表达方式，规范与运行数据仍归一化。没有根据截图缩放后像素猜测区域。

## 相邻边界与左右

前面FRONT_RIGHT/LEFT_SEAM跟随各自肩外侧与腋下可见线，背面BACK_LEFT/RIGHT_SEAM单独按背面肩胛/腋线确认。肩外侧归对应上肢，不设独立肩区。胸/上背保留躯干两侧；共用转折点以同一数组正向/反向复用，而非胸和上肢各画一条近似线。neck base连接颈与胸/上背，waist连接胸/腹、上背/腰背；flank在侧面空隙内衔接，整体人体门控剔除空气。

为避免修窄胸后留下下方分区重叠/空洞，同时统一头颈公共横线（正面y162、背面y130）、胸腹y315/背部y320和粗骨盆线y450；两腿在x200处分开，足外侧覆盖当前足型。骨盆线只是现有“腹部/腰背部”与“下肢”粗类的产品约定，不声称精确髋关节/会阴或医学分布。原8区域名称和ID不变，两个视图分别8项；正面人体左侧在屏幕右，背面人体左侧在屏幕左。

最终16个多边形在各自画布内闭合、无自交，同一视图任意区域对的内部面积无重叠（独立Shapely检查）；各自源bodyOutline内未分配面积为0。多边形可延伸到人体外，生效范围始终是outline与bodyOutline交集，不把臂躯/腿间空气当作选区。将来未支持区域仍使用unconfigured分支，不吸附最近点。边界沿用0.25逻辑单位容差，恰在公共边或极近边时可返回多个候选，列表确认；这不再用来容忍大块内部重叠。

## 配置版本与兼容性

人体素材、模板commons-neutral-v1/4.0.0、geometryId commons-blank-cc0-v1、400×900、坐标模块和整体命中轮廓均未修改。只把regionSetId从commons-blank-cc0-v1-ui-regions-1改为ui-regions-2。旧body-regions-v15.ts字节快照可用于比较或回退；回退须整体切回原区域模块及版本，不能混用新旧outline/bounds。

区域ID保持，但几何含义有修订。当前没有持久化区域选择、病灶或医学评估数据，不需要迁移历史业务记录。未来任何依赖粗区域几何的保存数据应绑定regionSetId、view与模板，旧版数据须按原区域解释或经显式迁移验证。调试点是模板/view/归一化点，其坐标意义不变；全新编译/重新进入可清除旧会话选择。医学atlas仍为空、未验证、禁用。

## 验证与证据性质

人工源图参考点保存于tests/miniprogram/fixtures/commons-region-references.json：38点，两面各19，包括胸侧、上臂、肩界内外、颈腹、间隙及公共界；期望是在看源PNG与20逻辑单位网格时独立指定，不由待测函数生成。Node核心PNG透明度解码核对体内/空气；实际fill命令路径与outline逐顶点比较，参考点再与独立射线法填色覆盖核对。

scripts/check_body_regions.py用既有Shapely检查16个简单闭合多边形、每面28个区域对、共享胸臂边、focus包含和源轮廓覆盖。几何结果不是医学有效性。
