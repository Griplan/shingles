# 数据最小采集与隐私约束

本文是项目内部处理规范，不代表完成法律合规审查或生产安全审计。V0 无照片上传、登录、病例保存或业务持久化，不应收集患者数据。新增数据功能前须明确目的、权限、授权、存储和删除流程，并以实际验证为准。

## 1. 最小采集

患者照片、身份信息及可关联个人的标注/诊疗背景视为敏感数据。多边形没有姓名也不保证无法关联患者。

核心规则映射原则上只需图谱版本、视图和归一化病灶多边形，不需要姓名、证件、电话、病历号或照片。不为潜在未来用途提前采集。照片分割获准后独立说明图像必要性，并保留手工路径。V0 evaluate 返回 501，不是可接收患者材料的业务入口，测试只发送合成内容。

## 2. 去标识化与受控访问

1. 优先合成或合法授权且去标识化的数据；无必要不获取真实患者材料。
2. 照片检查文件名、EXIF、位置、身份/病历标签、面部及背景身份线索；仅删文件名不足，内容需人工复核。
3. 真实身份映射表不入代码、实验目录或报告；确需关联时另行授权并隔离。
4. 真实数据存代码目录之外的受控位置，限制为任务所需人员访问；共享盘、云同步、跨设备复制和备份同样纳入管理。
5. 不把患者资料放公开仓库、issue、聊天、截图、录屏或交付样例；案例展示须在授权范围内再次脱敏检查。

## 3. 日志和错误限制

只保留必要技术时间、路由、状态、耗时和脱敏错误类型。不得记录完整请求/响应体、照片、Base64、完整标注载荷、身份、密钥、授权头或可关联患者的查询参数。

V0 未配置业务载荷日志，但开发服务器或基础设施可能有访问日志。不得在 URL 放敏感内容，保存/分享终端输出前检查；不能因应用未主动存储就宣称整个环境无任何日志。未来校验错误不可回显原始敏感输入，公共响应不含内部堆栈；故障复现使用合成输入。

## 4. 第三方模型与服务

V0 不调用外部 AI，不下载或运行模型。未来不得擅自发送照片、Mask、标注或可识别上下文到外部推理、分析、日志或遥测服务。

确需第三方时，先明确数据去向、处理目的、存储/训练使用方式、保留和删除机制、授权范围及必要评估，并获相应批准后实施。不能使用默认个人免费账户偷偷上传。权重合法不等于患者数据可外传。

本地模型也须检查来源/许可、外连依赖、缓存和临时文件位置。核心人工标注和规则系统应在无外部模型服务时运行。

## 5. 本地测试与 Git

- 几何夹具放 backend/tests/fixtures，标 synthetic，使用非医学名称。
- data/examples 只放合成、非患者接口示例；正式图谱目录不放病例材料。
- .gitignore 排除密钥、环境文件、私密配置、患者数据、模型权重、环境、缓存和输出，必要 .gitkeep 保留空目录。
- 新增文件及提交前检查实际内容；.gitignore 不会从历史移除已跟踪敏感文件，也不能代替访问控制。
- 不将真实 AppID、凭据或个人配置写入共享样例；分享日志、截图和打包前再次检查。

## 6. 保留与删除

| 数据 | 默认原则 | 后续需落实 |
| --- | --- | --- |
| V0 测试输入 | 仅合成，不收集病例 | 日志位置与清理范围 |
| 未来人工标注 | 当前会话，不默认持久化 | 清空/结束行为与状态清理测试 |
| 未来照片/Mask | 完成授权目的所需最短时间 | 明确保留期限、触发条件与责任人 |
| 日志/实验证据 | 仅必要脱敏材料 | 期限、权限、备份和清理策略 |
| 合法图谱/模型 | 按许可和版本追溯管理 | 许可限制、缓存清理与撤回条件 |

V0 无真实图像存储或自动删除服务，不能宣称已实现自动过期删除。新增保存功能时先确定具体期限和实现，再测试主动/到期删除、失败重试和备份处理。

删除范围覆盖原图、裁剪图、Mask、预览、临时文件、缓存、派生结果、意外日志副本和备份。备份不能立即删除时明确实际失效机制，不能把单目录清空当作全部删除。不得自动执行破坏性 Git 清理；发现已入库敏感资料先限制传播、报告脱敏事实，再按获准方案处理。

## 7. 发现问题与交付检查

停止复制/上传/继续输出敏感资料，定位文件及副本，向负责人报告脱敏范围和原因。修复后验证忽略、日志和删除路径，在 task.md 记录问题和处置，不覆盖历史掩盖问题。

未来交付检查覆盖输入、传输、存储、日志、第三方依赖、展示材料和删除流程。V0 的目录/忽略规则检查仅证明相应范围，不能代替完整系统隐私验证。

## 8. V4 实际数据流（覆盖V0历史占位描述）

只在用户点击“查看对应神经区域/重新计算”时，将已完成多边形、请求修订和模板/图谱身份通过POST发送至配置的后端。页面跳转只传会话ID。无照片、身份信息、外部AI请求、数据库或磁盘病例缓存；标注和结果只在本次运行内暂存，后端请求内计算后返回。默认模拟器使用本机回环，手机地址需单独配置。开发测试只用人工合成标记。

错误响应不回显输入或堆栈；应用不写完整载荷日志。开发示例使用--no-access-log，但系统/调试器可能另外采集网络记录，不能据此承诺整个环境没有日志。证据目录坐标JSON均为TEST合成样例，不含患者。正式医疗部署、授权及安全审计未完成。

## 9. V5.2 临时照片的实际生命周期

只有开发工具develop版、后端development/test并显式启用AI才允许使用；目前限定公开或合成测试图片，不面向患者。上传前展示目的/去向/保留及人工确认说明。仅发项目配置后端，不使用第三方AI。当前回环HTTP不是正式安全部署；真机入口禁用，未来需要合法HTTPS域名、身份授权、限流及运维审计，不能只改开关对外开放。

- 每次照片使用随机128位会话ID、独立256位能力令牌和随机照片ID；令牌只在请求头和运行内存，服务器只保存令牌哈希，不放URL或日志。其他会话令牌不能读图，未知/外来/过期统一410。能力令牌不是正式用户登录系统。
- 真正解码校验JPEG/PNG/WebP单帧，不信任扩展名或MIME。20MiB输入、12M像素、8192单边；提示JSON16KiB。最多8会话、2个写请求在途、1个推理，不建立数据库。
- 原始上传校验后立即删除；只存去EXIF且统一方向的PNG、Mask、alpha及轮廓。专用目录0700，无静态挂载；认证下载禁止缓存。程序不自动判断照片是否去标识化，禁止用患者图片验证本轮。
- 30分钟固定失效，访问时立即校验，运行中每30秒清理；取消/替换/返回请求删除原图及派生结果。服务正常关闭清理；异常终止的残留由下次独占启动清理。**服务停止时不能承诺30分钟内物理删除**，开发者负责检查残留。删除是文件系统逻辑删除，不是介质安全擦除；备份/系统缓存不在当前保证内。
- 前端不写持久存储，取消/替换会删除本功能下载的临时预览；不删除用户相册原件。删除网络失败展示提示，后端到期兜底。微信选图自身副本/系统缓存遵循平台生命周期，不宣称本功能能彻底擦除系统。
- 取消或超时的推理可能在内存中继续直到返回，但不再发布结果或重建已删除目录。确认结果仍是临时数据，返回会删除，不代表已存病例。

本轮实验证据仅含已授权CDC公开图片及synthetic图。输入、完整推理输出、模型、临时会话目录被Git忽略；文档中的微信截图使用同一公开样本/合成图。截图可能包含本机开发工具界面，不应据此推广为可分享真实病例截图的流程。实际TTL/隔离/删除测试见[V5.2记录](validation-records/v5.2/report.md)。

## 2026-11-01 受控云端临时处理

本轮已部署至用户授权的腾讯云独立服务，仅验证公开/合成图片；没有真实患者开放权限。请求经SSH加密通道、访问凭据加会话能力令牌保护，服务器照片目录0700，无静态公开访问；服务配置root0600，日志不输出照片或凭据。新域名/HTTPS、微信合法域名、正式用户授权和相关隐私合规尚未验收。

为满足用户独立暂停服务且不丢合法数据的要求，受控云端保存临时会话原子快照，仅持久化令牌摘要。未过期照片/Mask/原始几何/人工确认可跨停启恢复，30分钟expires_at不延长；取消立即删除。运行时30秒清理，停服时独立5分钟timer清理过期数据，因此物理删除可比会话失效晚约5分钟；损坏快照保留到下次启动检查，不泛化删除未知目录。并非新增病例数据库，V2人体标注生命周期仍由现有小程序会话控制。

本机private-data中的受控测试凭据不得提交、上传至其他服务或显示在截图；小程序只由用户输入并留内存。真机受控用户身份与正式照片处理政策需另行验收。见[部署报告](tencent-cloud-deployment.md)。

## P4 限时体验访问（2026-11-01）

管理员签发10分钟一次性邀请，客户端换取1小时访问，只存运行内存；后端仅留邀请/token摘要及随机授权principal，不收集微信个人资料，不声称微信身份认证。所有照片请求同时校验Bearer归属与照片key；跨授权会话统一拒绝，重启不改变固定失效时间。邀请通过可信渠道只给指定成员，不嵌入包/URL/日志。

照片临时处理及30分钟失效规则不变，仍只允许公开/合成测试图片；无B域名，尚未开放手机HTTPS或真实患者上传。平台相机/相册隐私声明、用户身份与真实患者合法授权需后续另行验收。见[P4报告](wechat-trial-integration.md)。

## P4.2 临时免邀请码测试补充

用户取消邀请资格限制，普通小程序自动建立临时会话。会话令牌用于隔离照片，不是身份认证，服务端不能验证微信开发调试，其他互联网客户端也可申请；保留容量/频率/上传/单推理限额。HTTP传输照片和临时令牌不加密，仍禁止真实患者图片，仅公开授权/合成测试。照片TTL/取消清理不变，自动会话固定1小时、只存摘要。测试后应关闭独立公网入口。
