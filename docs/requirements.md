# 需求与验收边界

项目：**dermatome-mapper（带状疱疹神经皮节辅助定位系统）**。目标是在微信原生小程序中将人工病灶标注与标准图谱进行空间映射，用于辅助定位、教学和研究。V0已完成，V1已由用户接受并结束迭代；V2人工标注代码已接入，真实运行验收待验证。唯一进度及结果见 [task.md](../task.md)，后续医学匹配仍为需求。

## 1. 目标和实施约束

核心流程是：选择人体正面/背面与身体区域 → 放大区域 → 多次点击标注并闭合多边形 → 后端计算图谱重叠 → 返回主要及相邻候选节段 → 高亮与解释。优先覆盖胸腹部与背部，先验证人工标注和规则映射，再考虑可选 AI。

预算 10000 元；第一阶段计划 1～2 周形成核心演示，第二阶段总计约 1 个月形成约定最终版本。这是规划约束，依赖合法图谱、医学审核与验证条件，不构成已完成承诺。采用 MVP、模块化、版本驱动和逐版本实验；只开发用户本轮授权的版本。

## 3. 版本需求（V1 已实现代码，V2～V5 未实现）

1. **V1 人体展示**：原创中性正背面模型、独立 UI 区域、按钮选择/高亮、局部放大与复位、等比例适配及纯坐标变换。V1 不以取得医学皮节图谱为前提，实际验收见 task.md。
   **V1.1 完善**：完整头颈及四肢、自然肤色二维插画、版本化资源与区域配置、轮廓命中、默认关闭且不持久化的单点坐标调试；真实触摸验证与纯数值测试分开。
   **V1.2 修复**：直接重绘下肢、胸腰髋、肩臂及手足几何，保留原模型，创建新模板并同步UI区域和同源命中；分别做坐标与位置配准测试、旧正面/新正面/新背面/参考点视觉对比。用户给出的头身和关节高度比例只作为插画设计参考。
2. **V2 病灶多边形标注、多区域管理与会话暂存**：逐点、连线、验证闭合、草稿撤销/取消、多片独立选中/删除、正背面隔离、同进程返回重入与范围复核。只在运行会话内暂存，缩放不改坐标，入口粗区不限制病灶范围；首版不做“清空全部”。详细边界与阶段门槛见[v2-plan.md](v2-plan.md)，业务仍未实现，全部新测试NOT_RUN。
3. **V3 空间映射**：验证多边形与图谱准入、计算交集和面积、排序候选、多病灶及边界处理。人工合成几何测试与医学验证分别开展。
4. **V4 业务集成**：图谱查询、标注评估、统一两端契约、错误处理和真实联调。
5. **V5 结果展示**：候选及皮节高亮、原标注、几何比例和医学提示，支持返回修改。

以上V1.1/1.2为历史需求，当前冻结的是Commons人体4.0.0与V1.6区域配置2，未继续采用旧原创人体；用户结束迭代不等于V1.x全部历史验证通过。区域放大属于 V1；病灶操作属于后续版本。V1 的人体浏览不等于已完成医学业务闭环。

## 4. 最终版本及可选扩展

最终交付以实际授权且验收的范围为准。V1～V5 构成核心演示，V6 在数据和审核条件满足时完善胸腹部/背部并评估侧面、头颈及四肢，V8 完成整体回归、隐私检查、真实部署验证和文档交付。

V7 的 SAM 类交互分割、病灶 Mask 和人工修正成本研究为可选。画笔、照片上传、左右侧面与 3D 人体等增强能力也不是 V0 或默认最终交付承诺。没有 AI，核心系统仍须独立运行。

## 5. 非功能需求

| 类别 | 可验证要求 |
| --- | --- |
| 技术 | 原生 TypeScript/WXML/WXSS，Canvas 2D；后端 Python 3.11+、FastAPI、Pydantic、Shapely、Pytest |
| 坐标 | 标准图谱 x、y ∈ [0,1]；正背面独立；DPR、屏幕尺寸、缩放和平移不改变原始标注 |
| 可解释性 | 未来结果说明图谱版本、候选、几何量分母和限制，不称为诊断置信度 |
| 数据可信度 | 图谱有来源、许可、版本、背景绑定和医学审核；未满足条件不得启用 |
| 解耦 | 前端交互、后端规则、可选 AI 分离；核心不依赖模型、GPU 或云推理 |
| 质量 | 核心几何开发时必须有独立单测；逐版本记录真实证据，保留失败记录 |
| 隐私 | 最小采集，不记录完整敏感载荷，不将患者资料入库或擅自上传第三方 |
| 性能 | 后续按目标设备和明确输入规模实际测量；V0 不承诺未测延迟或吞吐 |
| 可维护性 | 单体服务、明确类型、简单职责，不为未验证需求增加抽象层 |

## 6. 明确不支持与医学边界

V0 不实现人体/皮节绘制、Canvas 标注、多边形匹配、业务 payload 验证、照片上传、AI 识别、3D 或诊断规则。不引入数据库、Redis、Docker、Kubernetes、微服务、登录、复杂权限、云依赖或大模型 API。

本系统不是临床确诊工具。皮节存在个体差异和相邻重叠，不能把人体位置机械映射成唯一确定受累神经节。只能提供可能相关的候选，允许多候选和无匹配；不能把几何比例解释为医学概率。禁止编造皮节边界、参考文献或医学实验结论。

## 7. 验收边界

V0 核对结构文档、后端导入启动、health、基础 pytest、合法空图谱、小程序页面导航和敏感文件忽略规则。方法见 [validation.md](validation.md)，实际状态仅在 [task.md](../task.md) 记录。

类型/路径检查不能代替微信开发者工具编译、点击导航或真机验证；空图谱合法不等于医学可用；health/501 通过不等于业务评估实现；几何通过不等于医学映射正确。分别报告已完成、未完成和未验证，未执行项保持 NOT_RUN。
