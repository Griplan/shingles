# 带状疱疹神经皮节映射小程序 · 使用说明与快速上手指南

当前正式版可浏览人体和手动标注。图片辅助标注、轮廓放置和在线匹配只在开放这些功能的测试环境使用，测试时请勿上传真实患者照片。

欢迎使用本小程序！无论你是第一次接触的新手，还是刚上手的临床医护人员，花 **1 分钟**看懂这篇指南就能轻松完成标注。

---

## 1. 30 秒看懂这个小程序能做什么

这款小程序可以在人体示意图上标出目标位置。参考区域匹配开放时，会显示标注与参考图谱区域的面积重叠。

> **使用前请了解**
> - **仅供参考，不作确诊**：所有神经区域和占比都是按参考图谱算出来的辅助信息，**不能替代医生面诊和临床诊断**。
> - **记录仅本次暂存**：标注内容只在本次使用期间临时保留，关闭或重启小程序后不会长期保存，也不用于病例归档。

## 2. 两种标注方式怎么选？

打开首页后，你会看到两种方式：**「手动标注」**和**「图片辅助标注」**。一张表帮你秒选：

| 对比项 | 手动标注 | 图片辅助标注 |
| :--- | :--- | :--- |
| **适合什么情况** | 已经清楚疱疹长在身体哪个位置，想最快出结果；或没有拍患处照片 | 在测试环境使用公开授权示例图或合成图，按照片中的目标轮廓标注 |
| **怎么操作** | 直接在人体图上沿着疱疹位置点一圈 | 选择演示照片 → 框住目标提取轮廓 → 拖到人体对应位置 |
| **大概花多久** | 约 20～30 秒 | 约 1 分钟 |
| **操作难度** | 非常简单，新手首选 | 简单，跟着界面提示点即可 |

## 3. 方式一：手动标注（4 步搞定）

### 第 1 步：选好正面或背面，进入手动标注
1. 在首页上方切换**「正面」**或**「背面」**（也可以先轻点一下人体上的大致部位）。
2. 点击下方的**「手动标注」**卡片进入标注页。

### 第 2 步：沿疱疹边缘点一圈并闭合
1. 用手指沿着疱疹的边缘顺次轻点，至少点 **3 个点**（位置太小时，可以**两根手指张开放大**人体图，点得更准）。
2. 点错了一个点，可以点左下角**「撤销」**退回一步；想重画就点**「取消」**。
3. 圈完后点击右下角蓝色按钮**「闭合范围」**。

`[此处可配界面截图：手动圈选界面，标出人体上的标注点、双指放大提示以及底部「撤销 / 取消 / 闭合范围」按钮]`

### 第 3 步：补标其他部位，然后开始匹配
1. 如果还有别处疱疹，点左下角**「新增」**继续圈下一片；也可以在顶部切到**「正面 / 背面」**补标另一面。想删掉某一片，选中后点**「删除」**即可。
2. 全部标完后，点右下角**「完成标注」**，再点**「开始匹配」**，稍等片刻就会出现参考结果。

### 第 4 步：查看参考结果与结束流程
1. 结果出来后，你可以看到对应的神经区域名称和占比（竖屏手机显示在人体两侧的卡片里，横屏或折叠屏显示在右侧表格里）。
2. **点一下某个神经区域卡片**，人体图会单独高亮这一块；再点**「放大区域」**可拉近细看，看完点**「回到全身」**或**「查看全部」**恢复全图。
3. 想改范围就点左下角**「修改标注」**；全部看完准备给下一位患者使用时，点右下角蓝色按钮**「结束流程」**并确认，即可清空本次记录回到首页。

`[此处可配界面截图：参考结果页，标出两侧神经区域卡片、「放大区域 / 查看全部」和底部「修改标注 / 结束流程」按钮]`

## 4. 方式二：图片辅助标注（4 步搞定）

### 第 1 步：上传一张清晰的患处照片
1. 在人体区域标注页点击**「图片辅助标注」**。该入口仅在开放图片处理的环境显示。
2. 点击**「从相册选择」**选一张已有照片，或直接点**「拍照」**现拍一张。当前测试只使用公开授权示例图或合成图。照片经同意后上传至项目后端，仅用于本次自动化分割。新版本在确认轮廓并建立独立放置草稿后立即请求删除，退出时也会请求删除。当前测试后端闲置 2 分钟后回收，部署本轮后端更新后为 5 分钟。公网 HTTP 调试传输未加密，请勿上传真实患者照片。

> **3 条拍照小贴士（让目标清晰可见）**
> 1. **光线明亮均匀**：尽量在自然光或明亮室内拍，避开强反光和厚重阴影。
> 2. **距离适中对准患处**：让皮疹占画面中间较清楚的一块，不要离得太远拍成模糊小点。
> 3. **背景尽量干净**：避开杂乱衣物花纹遮挡，只露出需要观察的皮肤区域。

`[此处可配界面截图：AI 上传空态页，标出「从相册选择」和「拍照」两个按钮]`

### 第 2 步：框住目标，检查并确认轮廓
1. 照片显示后，用手指在照片上**拉一个框，把目标圈进去**，等待处理，页面会用绿色标出提取的范围。
2. 如果绿色范围已经贴合皮疹，直接点击蓝色按钮**「确认轮廓」**，再点**「放置到人体」**进入下一步。
3. **如果识别得不够准**，点下方的微调工具就能轻松修正：
   - **「重新圈选」**：重新拉框以提取轮廓；
   - **「换个候选轮廓」**：在几个候选轮廓之间切换；
   - **「修正范围」**：用画笔涂抹，选**「补充区域」**补上漏掉的皮疹，选**「擦除误选」**擦掉多选的正常皮肤，涂完点**「完成修正」**；
   - **「精细调整」**：在照片上轻点**「补充目标区域」**或**「排除误选区域」**，也支持**「补圈一处」**，再点**「重新提取」**。

`[此处可配界面截图：轮廓确认页，标出绿色轮廓、「确认轮廓」主按钮和下方微调工具盒]`

### 第 3 步：把病灶放到人体对应位置
1. 进入放置页后，先在上方选好**「正面」**或**「背面」**。
2. **拖动位置**：直接按住带蓝色虚线框的橙色病灶区域，拖到人体对应的部位上。
3. **微调大小和方向**：拖动下方**「调整大小」**和**「调整方向」**滑块，让它和实际患处比例一致；觉得太小看不清时，点**「放大轮廓」**拉近看，调完再点**「查看全身」**；调乱了随时点左下角**「重置调整」**恢复。

`[此处可配界面截图：自由放置页，标出橙色病灶虚线框、「放大轮廓」按钮以及「调整大小 / 调整方向」滑块]`

### 第 4 步：确认标注位置，查看参考结果
点击右下角蓝色按钮**「确认标注位置」**（若边缘稍微超出人体轮廓，按提示点**「检查越界并确认」**），系统会自动回到结果页展示参考神经区域。后续若想微调位置，可点击底部的**调整图片标注的位置**按钮回来修改；看完后同样点**「结束流程」**清空记录。

## 5. 特殊部位怎么标？（脚底、腋下、会阴等）

脚底、腋下和会阴等位置在全身图上不好看清，小程序专门准备了局部视图：

1. 在首页右上角点击**「特殊部位」**。
2. 选择需要标注的部位：**左脚底 / 右脚底**、**左腋下 / 右腋下** 或 **会阴区域**（提示：手部请直接在全身的正面或背面标注）。
3. 进入后操作和手动标注一样：沿边缘点选 → **「闭合范围」** → **「完成标注」** → 点击下方计算按钮查看参考区域；需要查看细节可点**「放大查看」**，再点**「回到全图」**恢复；结束后点**「结束流程」**或下方的**「返回特殊部位 / 返回全身人体」**。

> 部分特殊部位（如腋下、会阴等）当前仅支持人工手动圈选，不提供照片上传或轮廓提取。

## 6. 常见问题速查（FAQ）

**问 1：手动标注时点错了一个点，或者圈歪了怎么改？**\
答：还没闭合时，点底部**「撤销」**可以退回上一步，点**「取消」**可以重新开始；已经闭合或出结果了，点**「修改标注」**就能回来删掉重圈或新增区域。

**问 2：轮廓漏掉一块，或者把正常皮肤也圈进去了怎么办？**\
答：不用重头再来。在识别确认页先试试**「换个候选轮廓」**；如果还差一点点，点**「修正范围」**用画笔直接补涂或擦除，或者点**「精细调整」**轻点补充/排除即可。实在不理想也可以随时点底部**「返回手动标注」**。

**问 3：疱疹很小，放到人体图上时手指不好拖动怎么办？**\
答：小程序已经为极小病灶做了放大保护——即使病灶看起来只有米粒大，蓝色虚线框周围都留出了充足的抓取范围，**直接按住虚线框附近就能轻松拖起来**；你也可以先点**「放大轮廓」**放大后再微调。

**问 4：同一个人正面和背面都有疱疹，怎么一起标？**\
答：在标注页顶部的**「正面 / 背面」**切换条直接来回切换即可，两面的标注会同时保留。如果标注了多片区域，结果页还支持在**「全部标注」**和单条标注之间切换查看。

**问 5：给下一个人用之前，怎么快速清空刚才的记录？**\
答：在结果页右下角点击蓝色按钮**「结束流程」**，在弹出的提示框里点**「确认结束」**，系统会一键清空本次所有标注并返回首页。如果正在用 AI 传图，也可以点底部的**「取消并删除照片」**请求删除临时照片会话。

**问 6：上传的照片和标注记录会不会被永久保存或泄露？**\
答：不会。照片和标注仅在本次使用过程中临时处理，退出、取消或点击「结束流程」后会清理，不做病例存档，也不会把照片发给无关的第三方；建议拍照时尽量避开人脸、姓名牌等个人身份信息。
