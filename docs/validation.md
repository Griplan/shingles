# 验证方法与实验计划

本文规定方法，不维护第二份进度台账或预填成功结论。实际日期、环境、命令、输入、退出码、结果和证据统一追加到 [task.md](../task.md)，脱敏原始日志由其引用。未执行记 NOT_RUN，失败记 FAILED，有实际证据才记 PASSED。

V3图谱预览按[V3说明](v3-atlas.md)复现：`prepare_atlas.py` → `sync_atlas.py` → `check_preview_atlas.py` → 同步`--check`。另运行`test_atlas_geometry.py`、全部小程序测试、既有V2独立Shapely检查、后端pytest、粗UI区域与V0空图谱检查。技术数据校验必须暴露裁切前损失、简化微重叠及未配置范围；不要求为铺满人体虚构边界。页面测试包含正背全量、实际标签单区、左右/缺失视图、主动放大与复位、标签、重入及环境保护。V2隔离测试给其读写方法加抛错哨兵，确认预览动作不触及会话。资源预览与真实微信截图分别登记；医学审核仍须独立真实记录。

## 2. V1 坐标系统与后续 V2 输入验证

使用合法背景与预定义归一化参考点，覆盖四角、中心、边缘和不对称左右位置。比较多种尺寸/长宽比、DPR、留白、滚动、放大和平移，以及正背面切换。

将标准点投影再逆变换，记录实际显示矩形、坐标基准和误差；尺寸变化后重投影，确认原始点数组不变。检查解剖学左右与视图隔离，范围外点击明确拒绝而不静默裁切。数值往返误差目标 ≤1e-6，显示误差目标 ≤1 CSS px，均为待验证目标而非已测精度。模拟器与真机结果分开记录。

## 3. 几何算法（V3，NOT_RUN）

夹具放 `backend/tests/fixtures/` 并标 synthetic，区域使用非医学名称。用可手算矩形/三角形独立定义预期值，不使用被测函数自产预期结果。

| 场景 | 核验内容 |
| --- | --- |
| 完全包含 | 交集面积等于被包含图形面积，分母正确 |
| 部分相交 | 手算交集与比例一致 |
| 完全不相交 | 明确无匹配，不补默认区域 |
| 跨多个区域 | 候选覆盖、排序和同分处理符合约定 |
| 边界接触/附近 | 点线接触面积为零；极小面积与容差策略一致 |
| 多病灶 | 不连续轮廓合法；重叠病灶按约定避免重复计数 |
| 非法多边形 | 拒绝自交、零面积、点数不足、未闭合、重复、非有限和越界坐标 |
| 不支持结构 | 明确拒绝孔、多环和跨视图/错版标注 |
| 图谱区域重叠 | 不假定候选比例总和必为 1 |

补充有意义的性质检查：交集面积交换操作数不变、添加无关远处区域不改变已有结果、重复计算结果一致。容差、最小面积、点数上限与排序规则须先定义再测试。几何正确性不能替代医学正确性；缺医学图谱时可测试合成几何，医学映射仍禁用。

## 4. 前后端接口（V4，NOT_RUN）

冻结 Pydantic、TypeScript 和 docs/api.md 契约后测试正常输入、单/多病灶、无匹配、多候选和同分候选；逐项核对版本、视图、几何量和 UI。

异常测试包含缺字段、错误类型、越界/非有限数、非法几何和已定义资源上限；图谱测试包含不存在、空、未验证、许可不足、禁用及背景不一致。准入失败不能假装 HTTP 200 空候选。故障测试包含网络不可达、超时和服务异常，检查响应与日志不泄漏敏感输入。

开发者工具和真机联调分别记录服务地址、网络、请求域名配置及页面行为。V0 的 501 通过不算业务接口集成完成。

## 5. 医学映射（合格数据到位后，NOT_RUN）

核验来源、许可、版本、背景与审核范围。由具备相应背景的人员对照来源审核实际启用区域的标识、边界、左右和重叠，记录差异、争议与处置，不由开发者自行填补医学分布。

再用合法参考案例或专家确认的教学标注独立查看候选是否符合图谱与适用范围。几何数值、图谱审核与案例解释分开报告，不把任何一个通过等同于临床有效。

无授权样本、参考标准或适当审核时，不报告医学准确率。未来定量研究先明确样本来源、范围、参考标准、独立评阅、争议处理及个体级数据划分，实际执行后再报告。二维标准图谱不能证明某患者真实受累神经节。

## 7. V1 可复现自动测试

在 miniprogram 下执行 `npm run typecheck` 与 `npm test`。test 脚本用现有 TypeScript 编译整个小程序到临时目录，再由 Node 内置测试器执行根目录 `tests/miniprogram/*.test.cjs`，结束后仅清理自己创建的临时目录，不改写用户目录或产生小程序 JS 源文件。

坐标 A～J：手算正向/逆向、三种容器 11×11 点往返、宽高比和留白、区域居中和四角、放大/复位一致性、非法尺寸/区域/数值、边界点和正背面独立区域。断言误差阈值为 1e-9；不是临床精度或屏幕实测误差。容器样例为 280×460、343×540、700×570 CSS px。

Canvas 命令及节点替身检查正背面细节不同、轮廓剪裁高亮、DPR=1/2/3 物理尺寸、绝对变换、重复切换、hide/show/resize、detached 及旧异步查询失效、节点失败/重试、页面选择隔离。替身测试不验证微信绘制引擎或真实设备。

V0 回归保留 backend pytest（含 health 契约）、check_atlas.py 和 check_project.py。静态总检新增组件四文件、使用注册、Canvas type=2d、UI 数据/模型和测试脚本存在性。后端、API 版本及正式图谱不因 V1 前端开发改变。

## 8. 微信开发者工具与人工复核步骤

1. 导入现有 miniprogram 目录并点击“编译”，避免旧模拟器通道断开或样式热更新留下旧画布物理尺寸。记录工具/基础库版本、机型、屏幕/DPR。
2. 首页进入人体模型，默认 front/全身；完整头颈、双臂手、躯干、双腿足可见，比例正常。
3. 切 back，核对后枕/肩胛等细节区别；画面左右提示随视图变更。
4. 选择胸/腹或上背/腰背，按钮和当前名称更新，高亮限定在人体内；左右肢体按人体自身命名。
5. “放大查看”后目标居中、形状等比例；“返回全身”恢复完整人体并保留区域选择。
6. 在放大状态切视图，确认选择/缩放清空；反复正背面切换不累计变换。
7. 浏览 annotate/result 占位页并返回，再次进入模型检查初始化及重绘；不进行病灶采样。
8. 至少分别测试 320×568（DPR2）、390×844（DPR3）、430×932（DPR3）模拟器。页面可纵向滚动，检查无横向溢出、控件不重叠；换尺寸重新测量画布。模拟器不能等同真机。
9. V1～V1.2历史路径无图片解码；V1.3已用本地PNG，应实际检查两面加载/切面与错误提示，自动替身另测失败和重试。真实故障注入未运行须保持NOT_RUN。
10. 用真机补充显示与操作复核；实际设备、旋转及未覆盖基础库的结果单独记录，不从模拟器结果外推。

本节为操作协议，实际 PASS/FAIL/NOT_RUN、发现问题和修复结果统一在 task.md 与其引用的执行证据中记录，不提前在此填写成功结论。

## 9. V1.1 模型与坐标调试验证协议

自动运行仍为小程序目录npm run typecheck、npm test，另行执行backend pytest及两项检查。新增body-debug.test.cjs覆盖模板/资源路径、几何绑定、样式替换与错版拒绝、16区域、头颈放大、全身边距、左右对称、轮廓内外（含臂躯与腿间空隙）、曲线边缘、两类事件坐标、滚动和缩放不变性。Canvas测试扩展默认关闭、真实输入转发、十字重投影/隐藏、DPR、换面/关闭/旧回调、拖动/多指过滤、面板格式；替身不是实际微信引擎。

人工步骤（必须分别记录结果，不从V1旧结果继承）：
1. 完整编译进入模型页，确认V1.1、正面全身、默认调试关闭、头颈手足完整；记录工具/基础库、机型与DPR。热更新缺新模块/Babel辅助模块或原生图层残留时先重编译，仍有问题如实记录，不能以静态检查替代。
2. 选择头部、颈部及胸腹/背部/肢体，核对名称、高亮、居中放大、复位；局部视图只显示局部是预期，全身模式不得缺头。
3. 开启调试，轻点胸部；记录动态四位标准坐标、screen/canvas、模板/view和十字。十字中心与输入的像素差目标≤2 CSS px（触控/渲染检验目标，不是已测结果）；数值纯变换仍断言1e-9。
4. 保留该点选择胸部放大、复位、连续操作，标准坐标不变，十字重投影回同一位置；选择头部使胸部点离开视口时隐藏、不贴边；再复位出现原点。
5. 点击人体旁的逻辑画布内留白，提示“不在人体轮廓内”、无标准点和十字；点击模型适配矩形外留白，提示“超出模型范围”，不得吸附。检查双腿间隙及臂躯间隙。
6. 纵向滚动后重新点击，screen为页面可见区域CSS坐标，Canvas坐标独立，不使用旧top；移动超过8 CSS px或多指不生成调试点。
7. 换背面清空调试点与区域/放大，但可保留调试开关；背面另点并核对view。关闭调试后面板和十字均隐藏，重开不恢复旧点；正常按钮选择不受影响。
8. 分别运行320×568/DPR2、390×844/DPR3、430×932/DPR3；画布等比例、控件无横向溢出，开启面板不改变Canvas尺寸；离开/重入、旋转及真机分别补测。

原图形为本地路径，图片解码/加载失败不适用；Canvas初始化错误及查询失败仍须提示可重试。视觉审查是工程观察，不是医学审核。没有实际点击/像素测量证据的项目必须记NOT_RUN，即使模拟节点自动测试通过。
