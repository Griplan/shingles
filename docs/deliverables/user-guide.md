# 智络智绘小程序使用说明

智络智绘可以在人体示意图上标出皮肤可见异常的位置，并查看参考区域。你可以直接在人体图上**手动标注**，也可以在测试环境用**图片辅助标注**圈出演示照片里的范围。结果仅供参考，不能用于疾病诊断。

本说明按 2026 年 11 月 24 日核对的小程序版本编写。当前正式版可浏览人体和手动标注。图片辅助标注、轮廓放置与在线参考匹配仅在开放这些功能的测试环境使用。

## 方式一｜手动标注

1. 打开小程序，点**进入人体模型**。按实际位置选**正面**或**背面**。
2. 点**手动标注**。进入圈选页后，可在人体图上用两指张开放大。想回到整体画面，点**全身**。
3. 沿着要标注的范围边缘，依次轻点至少 3 个位置。点错一个位置，点**撤销**。
4. 点**闭合范围**。要标另一处，点**新增**再画。要删掉已经画好的某一处，选中该处后点**删除**。
5. 点**完成标注**。开放参考匹配时，小程序会自动计算。失败后可点**重试匹配**，或按页面提示重试。想继续编辑，点**修改标注**。

## 方式二｜图片辅助标注

1. 在人体模型页点**图片辅助标注**，再点**从相册选择**。测试时只选公开授权的示例图或合成演示图。照片经同意后发送至项目后端，仅用于本次自动化图像分割。当前线上测试后端连续闲置 2 分钟后回收。新版本在确认轮廓并建立独立放置草稿后立即请求删除，退出时也会请求删除。部署本轮后端更新后，闲置阈值为 5 分钟。使用公网 HTTP 测试时传输未加密。选清楚、光线自然、目标完整的图，尽量避开强反光、阴影和遮挡。
2. 照片显示后，用手指从目标一角拖到对角，把想圈出的范围框住。松手后等待提取轮廓。
3. 看彩色范围是否合适。框错了点**重新圈选**。有多个结果时可点**换个候选轮廓**。漏圈或多圈了一小块，可以点**修正范围**，用**补充区域**或**擦除误选**修改，完成后点**完成修正**。需要用点提示时，点**精细调整**，标出需要补充或排除的位置，再点**重新提取**。
4. 点**确认轮廓**，再点**放置到人体**。核对**正面**或**背面**，按住橙色范围拖到正确位置。用**调整大小**和**调整方向**改变形状的大小和角度。需要看清细节时点**放大轮廓**，再点**查看全身**恢复。
5. 点**确认标注位置**，等待参考结果。有一部分超出人体时，可继续移动，或按**检查越界并确认**的提示选择是否只保留人体里面的部分。位置已保存但计算失败时，可点**查看结果 / 重试计算**。

**照片中的范围由系统自动提取，人体上的位置由你自己确认。请核对正背面、左右侧和覆盖位置。**

## 特殊部位

在完整人体页面点**特殊部位**，可进入左脚底、右脚底、左腋下、右腋下或会阴示意图。这里使用手动标注。点**闭合范围**和**完成标注**后，再按页内按钮计算。腋下与会阴显示的是人工模拟分区，不能当作真实神经位置。私密部位请使用示意图手动标注，勿上传私密照片。

## 怎样看结果

人体上的标注轮廓是你确认的位置。彩色块表示与标注有重叠的参考区域，旁边的标签是图谱里的神经区域名称，百分比表示与标注重叠的面积比例。

- 点一个标签，可以单独看该区域。再次点同一个标签，或点**查看全部**，可恢复本次全部高亮。
- 标了多处时，可选**全部标注**或某一片。只有一片时直接显示结果。
- 点**修改标注**回去编辑。结果页出现**调整图片标注 … 的位置**时，可以用它重新放置对应的范围。标注只在本次使用中暂存，**结束流程**会清空本次记录。

## 常见问题

| 问题 | 怎样做 |
|---|---|
| 不知道具体部位名称怎么办？ | 选正面或背面后直接点**手动标注**，在人体图上找位置。 |
| 能先放大再画吗？ | 可以。在圈选页用两指张开放大，点**全身**恢复。 |
| 可以标多处吗？ | 可以。闭合一处后点**新增**。照片识别后也可按页面提示**补圈一处**。 |
| 画错了怎么办？ | 未闭合时点**撤销**。已经闭合的范围可选中后点**删除**并重画。 |
| 轮廓不合适怎么办？ | 试试**重新圈选**、**换个候选轮廓**或**修正范围**。也可返回手动标注。 |
| 照片过大怎么办？ | 小程序会尝试自动缩小。仍失败时，可用手机裁去无关边缘，保留完整目标，再选择一次。 |
| 可以选手机原始照片吗？ | 公开授权的演示原图或合成图可以直接选。常见 JPEG、PNG 可以尝试。HEIC 读不出时换成 JPEG 或 PNG。 |
| 为什么要我框选？ | 框告诉小程序你想圈照片中的哪一部分。 |
| 能跨腹部和腿部放置吗？ | 同一面图上的范围可以跨这两个部位。超出有效皮肤时，请调整位置或按页面提示检查。 |
| 放置完还能改吗？ | 结果页出现**调整图片标注 … 的位置**时可以重新放置。多片时可先选对应的标注。 |
| 等待很久怎么办？ | 先等当前操作结束。失败时用页面的重试按钮。若照片已过期，重新选择演示图，也可改用手动标注。 |
| 神经标签是医学诊断吗？ | 不是。它只表示你标的位置与图谱里哪些区域有重叠。没有匹配也不能排除疾病。 |
| 特殊部位与完整人体有什么区别？ | 特殊部位使用独立示意图手动标注，腋下和会阴使用模拟参考分区。 |
