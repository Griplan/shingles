# 用户手册配图清单

暂缺与当前源码逐页对版、可随手册转交的截图。以下为补拍清单。历史截图可用于内部参考，交付前应使用当前版微信模拟器或测试设备重拍。

| 编号 | 页面与画面 | 应突出的位置 |
|---|---|---|
| 1 | 首页客户视图 | 进入人体模型 |
| 2 | 完整人体正面 | 正面、背面、手动标注、图片辅助标注 |
| 3 | 同尺寸人体背面 | 背面选中状态 |
| 4 | 手动圈选，一片合成范围取点 | 撤销、闭合范围 |
| 5 | 合成手动范围闭合并完成匹配 | 合成轮廓及对应参考高亮 |
| 6 | 图片辅助标注初始页 | 从相册选择 |
| 7 | 照片轮廓页，分别保存拖框与候选两个画面 | 框的位置、确认轮廓 |
| 8 | 轮廓放置页 | 橙色范围、调整大小、调整方向、确认标注位置 |
| 9 | 轮廓放置后的参考结果 | 标注、彩色参考区、一个标签、修改标注 |

使用同一套匿名合成演示标注，AI 页面使用纯合成或具备公开授权的示例照片。导出模拟器视口，检查画面中无个人信息、测试凭据或开发面板。可标箭头或序号。图注应记录日期、构建版本和来源，并区分模拟器与真机。
